    Asincronia

    Antes de comenzar a ver cómo podemos interactuar con servidores HTTP en javascript, debemos entender bien un concepto fundamental para eso, la asincronía.

    El concepto de asincronía es fácil, en muchas ocasiones, una función no sabemos cuando terminará, como en el caso de una petición HTTP.

    Cuando realizamos una petición:

    1. La petición debe primero de resolver por DNS la URL a la que llamamos para saber cual es la IP del servidor.
    2. Debe enviar la petición a esa IP.
    3. La petición debe llegar al servidor.
    4. El servidor debe procesar la petición, ejecutar código según que hemos solicitado.
    5. El servidor envía la respuesta, esta debe llegar hasta nuestra IP.

    Todo este proceso lleva tiempo, pero no sabemos cuanto puede tardar, ni si quiera podemos saber si puede llegar a completarse.

    Sin la asincronia, nuestro código quedaría pausado hasta poder resolver todos esos pasos, usarla nos asegura que el resto del código puede seguir ejecutándose.

    Ejemplo

    Vamos a ver dos ejemplos de esto, uno sin asincronía, y otro asincrono, ambos parten de este html:

    <!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>Ejemplo asincronia</title>
  </head>
  <body>
    <h1>Ejemplo de asincronia</h1>
    <button id="random">Cambiar número</button>
    <button id="server">Llamar al servidor</button>

    <p id="valor">0</p>
    <script src="main.js"></script>
  </body>
</html>

    Ejemplo bloqueante

    En este ejemplo, en cuanto pulses Llamar al servidor, tu código queda bloqueado hasta que recibas la respuesta:

    const callServer = () => {
  const time = Math.floor(Math.random() * 5000 + 1000);
  const start = Date.now();
  while (Date.now() - start < time) {
  }
  return `Respuesta recibida después de ${time}ms`;
};

const randomValue = () => {
  const p = document.querySelector("#valor");
  const valor = Math.floor(Math.random() * 100);
  p.textContent = valor;
};

const serverButton = document.querySelector("#server");
const randomButton = document.querySelector("#random");

serverButton.addEventListener("click", () => {
  const h1 = document.querySelector("h1");
  h1.textContent = "Esperando al servidor...";
  const res = callServer();
  h1.textContent = res;
});

randomButton.addEventListener("click", randomValue);

    Ejemplo con asincronia

    En este ejemplo la función callServer() es asíncrona, si pulsas el botón continuamente en ningún momento el código queda bloqueado.

    const callServer = async () => {
  const time = Math.floor(Math.random() * 5000 + 1000);
  return new Promise((resolve) => {
    setTimeout(() => {
      resolve(`Respuesta recibida después de ${time}ms`);
    }, time);
  });
};

const randomValue = () => {
  const p = document.querySelector("#valor");
  const valor = Math.floor(Math.random() * 100);
  p.textContent = valor;
};

const serverButton = document.querySelector("#server");
const randomButton = document.querySelector("#random");

serverButton.addEventListener("click", async () => {
  const h1 = document.querySelector("h1");
  h1.textContent = "Esperando al servidor...";
  const res = await callServer();
  h1.textContent = res;
});

randomButton.addEventListener("click", randomValue);
