    Estructura de proyecto

    En cuanto a cómo organizar los diferentes archivos que componen un proyecto de html tenemos mucha libertad. No hay una forma fija, pero es buena idea estructurarla en diferentes directorios.

    Las diferentes etiquetas que referencian otros archivos dentro del proyecto necesitarán ajustarse para apuntar correctamente a los mismos dependiendo de que orden llevemos.

    Empecemos por la forma más simple de organizar una página, y luego comenzaremos a mejorar la estructura de la misma.

    Todo en la raiz

    Comenzaremos creando todo en la raiz del proyecto, acabaremos con estos archivos:

    .
├── about.html
├── index.html
├── projects.html
├── gato.png
├── main.js
└── style.css

    Crea los archivos, empieza por descargar esta imagen y añadirla al directorio donde estás creando la página:

    Luego crearemos index.html:

    <!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title></title>
    <link href="style.css" rel="stylesheet">
  </head>
  <body>
    <nav>
      <a href="index.html">Inicio</a>
      <a href="about.html">Sobre mi</a> 
      <a href="projects.html">Proyectos</a> 
    </nav>
    <h1>Mi web</h1>
    <p>Bienvenido a mi pagina web</p>
    <img src="gato.png" alt="un gatico">

    <script src="main.js"></script>
  </body>
</html>

    index.html es el archivo que el servidor nos envia cuando entramos a la raiz de nuestro servidor http, cuando entras a , es el archivo que se te manda.

    En una terminal, dentro de tu directorio de la página, lanza un servidor web con:

    python -m http.server

    Por defecto, tu servidor queda escuchando en el puerto 8000:

    ❯ python3 -m http.server
Serving HTTP on 0.0.0.0 port 8000 (http://0.0.0.0:8000/) ...

    Abre un navegador y ve a localhost:8000, podrás ver tu index.html renderizado por tu navegador.

    Tienes unos enlaces que apuntan a otros dos archivos, about.html y projects.html: 

    <a href="index.html">Inicio</a>
<a href="about.html">Sobre mi</a> 
<a href="projects.html">Proyectos</a>

    Si ahora mismo haces click en ellos, fallarán, ya que no existen.

    Vamos a crearlos:

    <!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title></title>
    <link href="style.css" rel="stylesheet">
  </head>
  <body>
    <nav>
      <a href="index.html">Inicio</a>
      <a href="about.html">Sobre mi</a> 
      <a href="projects.html">Proyectos</a> 
    </nav>
    <h1>Sobre mi</h1> 
    <p>Sección en la que hablo de mis estudios, mi trabajo y mis aficiones.</p>
  </body>
</html>

    <!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title></title>
    <link href="style.css" rel="stylesheet">
  </head>
  <body>
    <nav>
      <a href="index.html">Inicio</a>
      <a href="about.html">Sobre mi</a> 
      <a href="projects.html">Proyectos</a> 
    </nav>
    <h1>Proyectos</h1> 
    <p>Sección en la que hablo de mis proyectos</p>
  </body>
</html>

    Ahora los enlaces funcionan, pero si abrimos nuestra consola de desarrollo en el navegador con ctrl+shift+K:

    GET http://localhost:8000/style.css
[HTTP/1 404 File not found 4ms]
GET http://localhost:8000/main.js
[HTTP/1 404 File not found 3ms]
Ha fallado la carga del <script> con origen "http://localhost:8000/main.js".

    Encontramos dos errores, tenemos dos etiquetas:

    <link href="style.css" rel="stylesheet">
<script src="main.js"></script>

    Que referencian estos dos archivos, por un lado style.css nos permite cambiar como se debe renderizar cada etiqueta, por otro main.js nos permite añadir lógica mediante un lenguaje de scripting llamado Javascript.

    Creamos nuestro style.css:

    * {
  background: black;
  color: white;
}

h1 {
  color: hotpink;
}

    Y nuestro main.js:

    console.log("hola mundo")

    Cuando recargues la página principal verás que el estilo de tu página ha cambiado, y en la consola el mensaje "hola mundo", lanzado por javascript.

    El error de no encontrar favicon.ico se debe a que nos falta el archivo de icono que suele mostrarse en la pestaña superior, por ahora no te preocupes por el.

    La página es funcional, pero esta estructura solo nos vale para algo extremadamente sencillo, en cuanto empecemos a tener muchas imagenes, varios archivos html, css y js, todo empezará a ser caótico y dificil de navegar. Además, no hay separación de responsabilidades en los archivos, todo está mezclado.

    Separando responsabilidades

    Vamos a crear tres directorios:

    • css: Para nuestros archivos de estilo
    • scripts: Para los archivos de javascript
    • pages: Para las páginas independientes a index.html
    • imgs: Para las imagenes

    Mueve los archivos a sus directorios correspondientes, quedará asi:

    .
├── index.html
├── css
│   └── style.css
├── imgs
│   └── gato.png
├── pages
│   ├── about.html
│   └── projects.html
└── scripts
    └── main.js

    index.html debe estar en la raiz, o nuestro servidor no lo encontrará.

    Cuando ahora recargues la página, tu web dejará de funcionar correctamente, ni tiene el estilo de antes, ni los enlaces funcionan, ni el script se ejecuta, y es normal! debemos actualizar las referencias a esos archivos, por ejemplo:

    <!-- Antes -->
<a href="index.html">Inicio</a>
<a href="about.html">Sobre mi</a> 
<a href="projects.html">Proyectos</a> 

<!-- En la nueva estructura -->
<a href="index.html">Inicio</a>
<a href="pages/about.html">Sobre mi</a> 
<a href="pages/projects.html">Proyectos</a>

    Lo mismo pasa con nuestra imagen:

    <!-- Antes -->
<img src="gato.png" alt="un gatico">

<!-- En la nueva estructura -->
<img src="imgs/gato.png" alt="un gatico">

    Con el css:

    <!-- Antes -->
<link href="style.css" rel="stylesheet">

<!-- En la nueva estructura -->
<link href="css/style.css" rel="stylesheet">

    Y el script:

    <!-- Antes -->
<script src="main.js"></script>

<!-- En la nueva estructura -->
<script src="scripts/main.js"></script>

    También tendremos que modificar pages/about.html y pages/projects.html:

    <link href="../css/style.css" rel="stylesheet">

    Nota: Date cuenta del uso de ../ para indicar que tanto en about.html como en projects.html, el directorio esta un nivel por encima de donde están situados, pero en index.html no, podemos usar una ruta relativa como css/styles.css sin problema.

    Deberás actualizar también las rutas de ambas páginas:

    <a href="/index.html">Inicio</a>
<a href="/pages/about.html">Sobre mi</a> 
<a href="/pages/projects.html">Proyectos</a>

    De nuevo, aqui no nos vale con una ruta relativa como haciamos en index.html, hemos usado rutas absolutas, partiendo desde la raiz de nuestro proyecto.

    pages/about.html significa desde donde estoy, dentro del directorio pages, el archivo about.html /pages/about.html significa desde la raiz, dentro del directorio pages, el archivo about.html

    Expandir la estructura según necesidades

    Esta estructura solo es un ejemplo, encontrarás diferentes formas en muchos proyectos, al final, todo depende de que estés construyendo.

    Por ejemplo, en nuestra página solo estamos considerando el uso de imagenes, asi que un directorio de imgs basta, pero si usaramos diferentes fuentes multimedia, esta estructura nos ayudaría a mantener ordenado el proyecto:

    .
├── index.html
├── css
│   └── style.css
├── media
│   ├── imgs
│   │   └── gato.png
│   ├── sounds
│   │   ├── bell.mp3
│   │   ├── lose.mp3
│   │   └── win.mp3
│   └── videos
│       ├── intro.mp4
│       └── presentation.mp4
├── pages
│   ├── about.html
│   └── projects.html
└── scripts
    └── main.js

    Además, nada te obliga a tener un directorio como pages, ya has visto que obliga a tener que referenciar a otros archivos de formas diferentes.

    Debes analizar que ganas y que pierdes con cada estructura, si la página solo necesita dos o tres archivos html podríamos dejarlos en la raiz sin que molesten ni hagan demasiado ruido.
