    Etiquetas semánticas

    HTML5 introdujo etiquetas semánticas que definen el significado del contenido, mejorando la accesibilidad y el posicionamiento SEO.

    Contenedores genéricos

    Antes de HTML5, se usaban las etiquetas <div> y <span> para estructurar el contenido, pero no transmiten ningún significado semántico:

    • <div>: contenedor en bloque para agrupar elementos a nivel de bloque.
    • <span>: contenedor en línea para agrupar elementos a nivel de carácter.

    Ejemplo

    <div class="contenido-principal">
  <h2>Título</h2>
  <p>Un párrafo con <span class="resaltado">texto destacado</span>.</p>
</div>

    ¿Cuándo usar contenedores genéricos?

    Aunque las etiquetas semánticas son preferibles, <div> y <span> siguen siendo útiles cuando:

    • No existe una etiqueta semántica adecuada para el contexto.
    • Se necesita un contenedor exclusivamente para aplicar estilos CSS o comportamiento JavaScript.
    • Se trabaja con frameworks o componentes que requieren contenedores neutrales.

    Estructura básica

    <header>
  <h1>Título de la página</h1>
</header>

<nav>
  <a href="#seccion1">Sección 1</a>
  <a href="#seccion2">Sección 2</a>
</nav>

<main>
  <article id="seccion1">
    <h2>Artículo</h2>
    <p>Contenido principal...</p>
  </article>

  <article id="seccion2">
    <h2>Artículo</h2>
    <p>Contenido principal...</p>
  </article>

  <aside>
    <p>Contenido relacionado</p>
  </aside>
</main>

<footer>
  <p>© 2024 Mi sitio web</p>
</footer>

    Referencia

    Etiqueta Uso
    <header> Cabecera de página o sección
    <nav> Navegación principal
    <main> Contenido principal
    <article> Contenido independiente
    <section> Sección temática
    <aside> Contenido complementario
    <footer> Pie de página o sección

    Muchas librerias css utilizan html semántico para dar estilo a tu html usando directamente las etiquetas descritas anteriormente.

    Además, son críticas en el posicionamiento SEO, sin un buen uso de semántica a la hora de dividir tus contenidos.

    Regla general: usa etiquetas semánticas cuando transmitan el significado del contenido; reserva <div> y <span> para casos donde la semántica no aporta valor.
