    Atributos globales

    Los atributos globales son atributos que pueden aplicarse a cualquier elemento HTML. No todos tienen efecto en todos los elementos, pero están disponibles de forma general.

    Los más utilizados

    id

    Identifica de forma única un elemento en el documento. Solo puede haber un elemento con un id determinado:

    <h1 id="principal">Título principal</h1>
<div id="contenido">...</div>

    Se usa para:

    • Enlazar con enlaces internos (<a href="#principal">)
    • Seleccionar desde CSS (#principal { color: red; })
    • Seleccionar desde JavaScript (document.getElementById("principal"))

    class

    Asigna una o varias clases a un elemento. A diferencia de id, un mismo nombre de clase puede reutilizarse en múltiples elementos:

    <p class="destacado">Párrafo destacado</p>
<p class="destacado">Otro párrafo destacado</p>
<p class="normal">Párrafo normal</p>

    Se pueden asignar varias clases separadas por espacios:

    <div class="card destacado oscuro">Contenido</div>

    id es único por elemento, class es compartible. Piensa en id como un DNI y en class como una etiqueta de categoría.

    style

    Permite añadir estilos CSS directamente en el elemento (estilo en línea):

    <p style="color: blue; font-size: 18px;">Texto azul y grande</p>

    Aunque es útil para pruebas rápidas, se recomienda usar hojas de estilo externas o <style> en el <head> para mantener la separación entre contenido y presentación. Evita usarlos siempre que puedas, ensucian mucho tu html y para eso tenemos css

    title

    Añade un tooltip (texto informativo) que aparece al pasar el cursor sobre el elemento:

    <p title="Información adicional">Pasa el cursor sobre mí</p>
<a href="https://ejemplo.com" title="Ir a la página de ejemplo">Enlace</a>

    Atributos de eventos

    Permiten ejecutar código JavaScript cuando ocurre un evento en el elemento:

    <button onclick="alert('¡Hola!')">Haz clic</button>
<input onfocus="this.style.background='yellow'" onblur="this.style.background='white'">
<div onmouseover="this.style.color='red'" onmouseout="this.style.color='black'">
  Pasa el cursor
</div>
    Atributo Se dispara cuando...
    onclick Se hace clic en el elemento
    onmouseover El cursor entra en el elemento
    onmouseout El cursor sale del elemento
    onfocus El elemento recibe el foco
    onblur El elemento pierde el foco
    onkeydown Se presiona una tecla
    onchange El valor del campo cambia y pierde el foco

    En la práctica, los eventos se gestionan desde JavaScript en vez de usar atributos inline, pero es útil conocer su existencia.

    Atributos de datos personalizados (data-*)

    Permiten almacenar información privada en un elemento sin afectar al renderizado. El valor se lee desde JavaScript con dataset:

    <article data-id="42" data-categoria="noticias">
  <h2>Título del artículo</h2>
</article>

    const article = document.querySelector("article");
console.log(article.dataset.id);         // "42"
console.log(article.dataset.categoria);  // "noticias"

    Los nombres de los atributos data-* pueden ser cualquier palabra válida, siempre que empiece por data-.

    Atributos de accesibilidad

    hidden

    Oculta el elemento de la página. No se renderiza ni ocupa espacio:

    <p hidden>Este párrafo no se ve</p>

    Equivalente a display: none en CSS, pero semántico.

    Atributos de internacionalización

    lang

    Especifica el idioma del contenido del elemento. Es heredado por los elementos hijos:

    <html lang="es">
  <body>
    <p>Este texto está en español.</p>
    <p lang="en">This text is in English.</p>
  </body>
</html>

    dir

    Define la dirección del texto:

    <p dir="ltr">Texto de izquierda a derecha (por defecto)</p>
<p dir="rtl">Texto de derecha a izquierda (árabe, hebreo)</p>

    Para la lista completa de atributos globales, consulta la documentación de MDN sobre atributos globales.
