    Tablas

    Las tablas permiten organizar datos en filas y columnas, ideal para presentar información estructurada como comparativas, precios o datos estadísticos.

    Estructura básica

    Una tabla se construye con las etiquetas <table>, <tr> (fila), <th> (cabecera) y <td> (celda de datos):

    <table>
  <tr>
    <th>Nombre</th>
    <th>Edad</th>
    <th>Ciudad</th>
  </tr>
  <tr>
    <td>Ana</td>
    <td>25</td>
    <td>Madrid</td>
  </tr>
  <tr>
    <td>Carlos</td>
    <td>30</td>
    <td>Barcelona</td>
  </tr>
</table>

    La etiqueta <th> renderiza el texto en negrita y centrado por defecto, indicando que es un encabezado de columna o fila.

    Etiquetas de la tabla

    Etiqueta Uso
    <table> Contenedor principal de la tabla
    <tr> Define una fila
    <th> Celda de encabezado
    <td> Celda de datos
    <thead> Agrupa el encabezado de la tabla
    <tbody> Agrupa el cuerpo de la tabla
    <tfoot> Agrupa el pie de la tabla

    Cabecera y pie de tabla

    Para separar semánticamente el encabezado, cuerpo y pie de la tabla:

    <table>
  <thead>
    <tr>
      <th>Producto</th>
      <th>Precio</th>
      <th>Stock</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Portátil</td>
      <td>899 €</td>
      <td>12</td>
    </tr>
    <tr>
      <td>Tablet</td>
      <td>349 €</td>
      <td>25</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <td>Total productos</td>
      <td colspan="2">2</td>
    </tr>
  </tfoot>
</table>

    Spanning: colspan y rowspan

    Las celdas pueden ocupar múltiples columnas o filas con los atributos colspan y rowspan:

    <table>
  <tr>
    <th colspan="2">Información personal</th>
    <th>Contacto</th>
  </tr>
  <tr>
    <td>Nombre</td>
    <td>Ana García</td>
    <td>ana@correo.com</td>
  </tr>
  <tr>
    <td rowspan="2">Dirección</td>
    <td>Calle Mayor 10</td>
    <td>600 123 456</td>
  </tr>
  <tr>
    <td>28001 Madrid</td>
    <td>—</td>
  </tr>
</table>
    Atributo Uso
    colspan Número de columnas que ocupa la celda
    rowspan Número de filas que ocupa la celda

    Atributos de la tabla

    Atributo Uso
    border Ancho del borde de la tabla (obsoleto, usar CSS)
    cellpadding Espacio interior de las celdas (obsoleto)
    cellspacing Espacio entre celdas (obsoleto)
    width Ancho de la tabla (obsoleto)

    Los atributos de presentación como border, cellpadding y cellspacing están obsoletos en HTML5. Se recomienda usar CSS para dar estilo a las tablas.

    Tabla accesible

    Para mejorar la accesibilidad de las tablas, se pueden usar las siguientes buenas prácticas:

    • Usar <thead>, <tbody> y <tfoot> para la estructura semántica
    • Incluir un <caption> con la descripción de la tabla
    • Usar scope="col" o scope="row" en las celdas de encabezado
    <table>
  <caption>Ventas trimestrales 2024</caption>
  <thead>
    <tr>
      <th scope="col">Trimestre</th>
      <th scope="col">Ventas</th>
      <th scope="col">Beneficio</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">Q1</th>
      <td>15.000 €</td>
      <td>3.500 €</td>
    </tr>
    <tr>
      <th scope="row">Q2</th>
      <td>18.000 €</td>
      <td>4.200 €</td>
    </tr>
  </tbody>
</table>

    El elemento <caption> proporciona un título visible a la tabla que ayuda a los usuarios de tecnologías asistivas a entender su contenido.

    Tablas fáciles

    La forma más fácil de crear la estructura de una tabla es usar un .csv + csvlook + multimarkdown:

    Partiendo de un csv como este:

    id,username,email,password
1,pablo,pablo@gmail.com,pablopass
2,maria,maria@gmail.com,mariapass
3,javier,javier@proton.me,javierpass

    Solo necesitas usar pipes:

    /tmp/test
❯ cat users.csv
id,username,email,password
1,pablo,pablo@gmail.com,pablopass
2,maria,maria@gmail.com,mariapass
3,javier,javier@proton.me,javierpass
