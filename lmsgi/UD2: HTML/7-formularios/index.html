    Formularios

    Los formularios permiten al usuario enviar datos al servidor. Son la forma principal de interacción en una página web los verás en un buscador, formulario de registro, en como dejar comentarios, subir fotos a una red social, etc.

    La etiqueta <form>

    Un formulario se define con la etiqueta <form>, que actúa como contenedor de todos los campos de entrada:

    <form action="/enviar" method="post">
  <label for="nombre">Nombre:</label>
  <input type="text" id="nombre" name="nombre">

  <button type="submit">Enviar</button>
</form>
    Atributo Uso
    action URL a la que se envían los datos
    method Método HTTP: get (datos en la URL) o post (datos en el cuerpo)
    enctype Tipo de codificación (application/x-www-form-urlencoded, multipart/form-data)

    Los atributos action y method se usan cuanto el backend procesa los datos enviados como un formulario HTTP clásico.

    En muchas ocasiones el backend espera un JSON, en ese caso, no se añaden estos atributos, y usaremos JavaScript para capturar los valores y enviarlos como un objeto.

    Usa multipart/form-data como enctype cuando el formulario incluya subida de archivos con <input type="file">.

    Inputs de texto

    Los campos de texto son los más utilizados para recopilar información del usuario:

    <form>
  <input type="text" name="usuario" placeholder="Nombre de usuario">
  <input type="password" name="contrasena" placeholder="Contraseña">
  <input tyl backend espera unail" name="correo" placeholder="correo@ejemplo.com">
  <input type="number" name="edad" min="0" max="150">
  <input type="tel" name="telefono" placeholder="600 123 456">
  <input type="url" name="web" placeholder="https://ejemplo.com">
  <input type="search" name="busqueda" placeholder="Buscar...">
</form>
    Tipo Uso
    text Texto general, una sola línea
    password Texto oculto (muestra puntos o asteriscos)
    email Correo electrónico (validación automática del formato)
    number Número con flechas de incremento/decremento
    tel Teléfono (en móviles abre el teclado numérico)
    url URL completa (validación automática)
    search Campo de búsqueda (puede mostrar botón de limpiar)

    Selección

    Checkbox

    Permite seleccionar una o varias opciones de una lista:

    <fieldset>
  <legend>Idiomas</legend>

  <label>
    <input type="checkbox" name="idiomas" value="es"> Español
  </label>
  <label>
    <input type="checkbox" name="idiomas" value="en"> Inglés
  </label>
  <label>
    <input type="checkbox" name="idiomas" value="fr"> Francés
  </label>
</fieldset>

    Radio

    Permite seleccionar una sola opción de una lista. Todas las opciones deben compartir el mismo name:

    <fieldset>
  <legend>Turno</legend>

  <label>
    <input type="radio" name="turno" value="manana"> Mañana
  </label>
  <label>
    <input type="radio" name="turno" value="tarde"> Tarde
  </label>
  <label>
    <input type="radio" name="turno" value="noche"> Noche
  </label>
</fieldset>

    Diferencia clave: checkbox permite múltiples selecciones, radio solo permite una. El atributo name agrupa los radios para que solo uno se pueda seleccionar a la vez.

    Fecha, hora y color

    <form>
  <input type="date" name="nacimiento">
  <input type="time" name="hora">
  <input type="color" name="color-favorito">
  <input type="range" name="volumen" min="0" max="100">
</form>
    Tipo Uso
    date Selector de fecha (día, mes, año)
    time Selector de hora
    color Selector de color (abre el selector del sistema)
    range Slider para seleccionar un valor en un rango

    Subida de archivos

    El campo file permite al usuario seleccionar archivos de su dispositivo:

    <input type="file" name="avatar" accept="image/*">
    Atributo Uso
    accept Tipos de archivo permitidos (image/*, .pdf, .jpg,.png)
    multiple Permite seleccionar varios archivos 
    <!-- Solo imágenes -->
<input type="file" name="fotos" accept="image/*" multiple>

<!-- Documentos PDF y Word -->
<input type="file" name="documento" accept=".pdf,.doc,.docx">

    Textarea

    Para campos de texto de múltiples líneas, como comentarios o descripciones:

    <textarea
  name="mensaje"
  rows="5"
  cols="40"
  placeholder="Escribe tu mensaje aquí..."
></textarea>
    Atributo Uso
    rows Número visible de filas
    cols Número visible de columnas
    minlength Longitud mínima del texto
    maxlength Longitud máxima del texto

    Botones

    <button type="submit">Enviar</button>
<button type="reset">Limpiar</button>
<button type="button">Acción personalizada</button>
    Tipo Uso
    submit Envía el formulario (valor por defecto)
    reset Limpia todos los campos del formulario
    button Botón sin comportamiento por defecto (para JavaScript)

    Select

    El elemento <select> crea un desplegable con opciones:

    <select name="pais" required>
  <option value="" disabled selected>Selecciona un país</option>
  <option value="es">España</option>
  <option value="mx">México</option>
  <option value="ar">Argentina</option>
</select>

    Para agrupar opciones, se usa <optgroup>:

    <select name="tecnologia">
  <optgroup label="Frontend">
    <option value="html">HTML</option>
    <option value="css">CSS</option>
    <option value="js">JavaScript</option>
  </optgroup>
  <optgroup label="Backend">
    <option value="python">Python</option>
    <option value="java">Java</option>
    <option value="go">Go</option>
  </optgroup>
</select>

    Label

    La etiqueta <label> asocia un texto descriptivo con un campo de formulario. Esto mejora la accesibilidad y permite hacer clic en el texto para enfocar el campo:

    <!-- Forma 1: usando for/id -->
<label for="email">Correo electrónico:</label>
<input type="email" id="email" name="email">

<!-- Forma 2: anidando el input dentro del label -->
<label>
  Contraseña:
  <input type="password" name="contrasena">
</label>

    Siempre asocia un <label> a cada input. Los lectores de pantalla lo necesitan para indicar al usuario qué campo está completando.

    Fieldset y legend

    <fieldSet> agrupa campos relacionados visualmente y semánticamente. <legend> define el título del grupo:

    <form action="/registro" method="post">
  <fieldset>
    <legend>Datos personales</legend>

    <label for="nombre">Nombre:</label>
    <input type="text" id="nombre" name="nombre" required>

    <label for="email">Correo:</label>
    <input type="email" id="email" name="email" required>
  </fieldset>

  <fieldset>
    <legend>Dirección</legend>

    <label for="calle">Calle:</label>
    <input type="text" id="calle" name="calle">

    <label for="ciudad">Ciudad:</label>
    <input type="text" id="ciudad" name="ciudad">
  </fieldset>

  <button type="submit">Registrarse</button>
</form>

    Validación básica

    HTML5 incluye validación integrada sin necesidad de JavaScript:

    Atributo Uso
    required El campo es obligatorio
    placeholder Texto de ejemplo que desaparece al escribir
    minlength Longitud mínima de caracteres
    maxlength Longitud máxima de caracteres
    min Valor mínimo (para number, date)
    max Valor máximo (para number, date)
    pattern Expresión regular que debe cumplir el valor 
    <form>
  <input type="text" name="usuario" required minlength="3" maxlength="20">
  <input type="email" name="correo" required placeholder="correo@ejemplo.com">
  <input type="number" name="edad" min="18" max="120">
  <input type="text" name="codigo" pattern="[A-Z]{3}-[0-9]{4}" title="Formato: ABC-1234">
  <button type="submit">Enviar</button>
</form>

    El atributo title se muestra como pista cuando la validación falla. Es útil para explicar el formato esperado en campos con pattern.

    Servidor de pruebas

    Este servidor de backend está creado con node y la librería express:

    import express, { type Request, type Response } from "express"
import cors from "cors"

const app = express()
const port = 3000

app.use(cors())
app.use(express.urlencoded({ extended: true }))
app.use(express.json())

app.get("/", (req: Request, res: Response) => {
  res.send("Hola mundo")
})

app.post("/http-form", (req: Request, res: Response) => {
  const datos = req.body as Record<string, string>

  console.log("Datos recibidos:", datos)

  res.send(`Recibido: ${JSON.stringify(datos)}`)
})

app.post("/json-form", (req: Request, res: Response) => {
  const datos = req.body as Record<string, string>

  console.log("Datos recibidos:", datos)

  res.json({ recibido: datos })
})

app.listen(port, () => {
  console.log(`Servidor funcionando en localhost:${port}`)
})

    Tiene tres endpoints, es decir, rutas a las que podemos llamar desde un cliente para recibir texto mediante peticiones GET o enviar datos mediante peticiones POST.

    Para levantarlo usaremos bun, un runtime de javascript que nos permite usar este lenguaje para crear servidores http.

    Crea un directorio para desarrollar el servidor, una vez dentro, ejecuta:

    bun init
bun add express express@types

    Luego, en index.ts añade el código adjunto anteriormente.

    Luego, lanza el servidor con bun index.ts:

    ❯ bun run index.ts 
Servidor funcionando en localhost:3000

    Puedes crear otro servidor aparte para probar a enviar datos a http://localhost:3000/http-form.

    Tambien dispone de una ruta /json-form que usaremos para aprender a realizar envios de datos en json con javascript mas adelante.
