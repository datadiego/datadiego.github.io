    Introducción

    Markdown es un lenguaje de marcado extremadamente simple, pero muy versátil.

    Te va a acompañar en toda tu vida como desarrollador, asi que es importante que cojas soltura utilizándolo a diario.

    Es el lenguaje perfecto para que tomes notas en clase y las puedas mantener organizadas. En un futuro podrás convertir todo eso en una página web personal de consulta con cualquier cosa que necesites recordar.

    Además, la mayoría de conceptos que usamos en markdown estarán presentes en HTML, si no eres capaz de estructurar texto en este lenguaje, será difícil utilizar HTML de manera efectiva.

    Elementos

    Headings

    Los elementos principales de estructura para el texto. Se utilizan para crear una jerarquía de importancia a los diferentes contenidos del documento.

    Los headings se caracterizan por el uso de #, cuantos más #, más bajo está en la jerarquía de la estructura:

    # Titulo
## Sección 1
### Sección 1.1
### Sección 1.2
#### Sección 1.2.1
## Sección 2
### Sección 2.1

    Por ejemplo, en un libro de recetas podríamos tener:

    # Recetas

## Pan

### Ingredientes

### Pasos

### Consejos

## Pasta

### Ingredientes

### Pasos

### Consejos

    Es importante mantener una jerarquía coherente, no puedes pasar de un nivel 3 a un nivel 5 sin pasar por el nivel 4. Pero si puedes pasar de un nivel 5 a un nivel 3 si continuas con el tema declarado en ese nivel.

    Generalmente, cada heading se renderiza más pequeño a más # tenga.

    Heading 1

    Heading 2

    Heading 3

    Heading 4

    Solo debes tener un heading de nivel 1 en tus documentos. Es el titulo principal del documento, tener varios provocará errores en muchos programas de terceros y te confundirá a la hora de interpretarlos.

    Listas

    A la hora de listar elementos, tienes dos tipos:

    Desordenadas

    Listas de elementos que no necesitan un orden determinado, como los ingredientes de una receta, los datos de un usuario, o las dependencias de un proyecto:

    - Tomate
- Harina
- Sal
- Agua

    Ordenadas

    Listas de elementos que necesitan ir en un orden determinado:

    1. Elemento 1
2. Elemento 2
3. Elemento 3
4. Elemento 4

    Hipervínculos

    Puedes enlazar páginas externas usando estos elementos:

    [texto](url.com)
[mi blog](datadiego.github.io)

    Tablas

    Markdown puede renderizar tablas para organizar datos:

    | id | username | email            | password   |
| -- | -------- | ---------------- | ---------- |
|  1 | pablo    | pablo@gmail.com  | pablopass  |
|  2 | maria    | maria@gmail.com  | mariapass  |
|  3 | javier   | javier@proton.me | javierpass |
    id username email password
    1 pablo pablo@gmail.com pablopass
    2 maria maria@gmail.com mariapass
    3 javier javier@proton.me javierpass

    La forma más cómoda que conozco de crear tablas para markdown es crear un csv + csvlook:

    /tmp/test

    Código

    Puedes compartir código para que aparezca en un recuadro con fuente monoespaciada, resaltado de sintaxis y un botón que permita a los usuarios copiar el código a un lado.

    Tienes dos tipos:

    Código inline

    Cuando haces referencia a algun concepto de programación, el nombre de un comando, una función o en general cualquier cosa que el usuario no necesite copiar o no tenga mas de una linea.

    Por ejemplo:

    La funcion console.log("hola mundo") no funcionará en html si no hemos cargado el archivo javascript necesario con <script src="archivo.js"></script>.

    Bloques de código

    Los más útiles, tienen resaltado de sintáxis, permiten más de una linea de código y copiar el código rápidamente.

    Utiliza triple comilla invertida para encerrar tu código en markdown:

    ```python
print("Hola mundo")
```

    Esto resultará en:

    print("Hola mundo")

    Necesitas añadir el lenguaje que usas para activar el resaltado como viste en el ejemplo anterior de python, unos ejemplos:

    Sin resaltado:

    console.log("hola mundo");

    Javascript:

    console.log("hola mundo");

    HTML:

    <ul>
  <li>Café</li>
  <li>Agua</li>
  <li>Azúcar</li>
</ul>
