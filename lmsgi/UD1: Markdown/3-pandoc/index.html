    Pandoc

    Pandoc es un paquete para Linux que convierte markdown a multiples formatos.

    Permite modificar muchos aspectos del renderizado, y es perfecto para crear PDF a partir de tus archivos.

    Instalación

    Como mínimo necesitas:

    sudo dnf install pandoc texlive-scheme-basic -y

    Para ciertas operaciones puedes necesitar algunos paquetes extra.

    Uso

    Es bastante simple convertir a pdf cualquier archivo markdown:

    pandoc -i archivo.md -o salida.pdf

    Scripting

    Para operaciones más avanzadas, es preferible crear un script en bash:

    #!/bin/bash

show_help() {
    cat <<EOF
Uso: $(basename "$0") [opciones] archivo.md

Convierte un archivo Markdown a PDF usando pandoc.

Opciones:
  -o, --output FILE     Nombre del archivo de salida (default: input.pdf)
  -m, --margins STRING  Márgenes (ej: 2.5cm, 1in, "2cm 3cm 2cm 3cm")
  -f, --font NAME       Fuente principal del documento
  -l, --list-fonts      Lista las fuentes disponibles en el sistema
  -h, --help            Mostrar esta ayuda

Notas:
  - Al especificar fuente se usa xelatex como motor de PDF.
  - Si pasas --font sin nombre, se listan las fuentes disponibles.

Ejemplos:
  $(basename "$0") documento.md
  $(basename "$0") -m 3cm documento.md
  $(basename "$0") -l
  $(basename "$0") -f "Liberation Serif" documento.md
  $(basename "$0") -m "2cm 3cm 2cm 3cm" -f "DejaVu Sans" -o salida.pdf documento.md
EOF
}

list_fonts() {
    if ! command -v fc-list >/dev/null; then
        echo "Error: 'fc-list' no está disponible (paquete fontconfig)." >&2
        exit 1
    fi
    fc-list : family | sed 's/,.*//' | sort -u
}

OUTPUT=""
MARGINS=""
FONT=""

while [[ $# -gt 0 ]]; do
    case "$1" in
        -o|--output)
            OUTPUT="$2"
            shift 2
            ;;
        -m|--margins)
            MARGINS="$2"
            shift 2
            ;;
        -f|--font)
            if [[ -z "$2" || "$2" == -* ]]; then
                echo "Fuentes disponibles en el sistema:"
                list_fonts
                exit 0
            fi
            FONT="$2"
            shift 2
            ;;
        -l|--list-fonts)
            list_fonts
            exit 0
            ;;
        -h|--help)
            show_help
            exit 0
            ;;
        *)
            INPUT="$1"
            shift
            ;;
    esac
done

if [[ -z "$INPUT" ]]; then
    echo "Error: Debes especificar un archivo .md" >&2
    echo "Para ver las fuentes disponibles: $(basename "$0") -l" >&2
    show_help
    exit 1
fi

if [[ ! -f "$INPUT" ]]; then
    echo "Error: El archivo '$INPUT' no existe" >&2
    exit 1
fi

if [[ -z "$OUTPUT" ]]; then
    OUTPUT="${INPUT%.md}.pdf"
fi

ARGS=()

if [[ -n "$MARGINS" ]]; then
    ARGS+=("-V" "geometry:margin=$MARGINS")
fi

if [[ -n "$FONT" ]]; then
    if ! command -v xelatex >/dev/null; then
        echo "Error: Se necesita xelatex para cambiar la fuente." >&2
        exit 1
    fi
    ARGS+=("--pdf-engine=xelatex" "-V" "mainfont=$FONT")
fi

pandoc "$INPUT" -o "$OUTPUT" "${ARGS[@]}"
echo "Generado: $OUTPUT"

    Para usarla, copialo a un archivo, por ejemplo md2pdf.sh, dale permisos y ejecuta:

    chmod +x ./md2pdf.sh
./md2pdf.sh -i guia.md -m 2cm -f "JetBrainsMono Nerd Font"

    Es fácil crear una herramienta simple que te permita crear un PDF personalizado con cualquier agente, una vez tengas una herramienta que se ajuste a tus necesidades no vas a volver a necesitar un editor de texto para crear PDFs, markdown ya tiene todo lo que necesitas para crear texto enriquecido.

    Si tu herramienta es general y sirve para múltiples propósitos puedes moverla a /usr/local/bin y ejecutarla desde cualquier sitio
