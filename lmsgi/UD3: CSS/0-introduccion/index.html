    Introducción

    CSS (Cascading Style Sheets) es un lenguaje declarativo que sirve para cambiar cómo una página se renderiza en el navegador.

    Sintaxis

    Su sintaxis es simple, al ser declarativa debes pensar en que quieres, no en como se logra.

    Se compone de solo tres elementos, un selector, un atributo y un valor para el mismo:

    h1 {
  color: hotpink;
  border: 1px solid black
}

    En este caso, nuestro selector es h1, tenemos dos atributos, color y border, cada uno con un valor asignado.

    Cómo aplicar CSS

    Hay tres formas de aplicar estilos a un documento HTML:

    Archivo externo (la más usada y recomendada): se enlaza desde el <head> con <link>. Mantiene el HTML separado de los estilos.

    <link href="style.css" rel="stylesheet">

    Etiqueta <style>: permite escribir CSS directamente dentro del <head> del documento. Útil para estilos que solo afectan a una página.

    <style>
  h1 { color: hotpink; }
</style>

    Atributo style (inline): aplica estilos directamente a un elemento. Es el menos recomendado porque mezcla presentación con contenido y repite reglas.

    <h1 style="color: hotpink;">Título</h1>

    Modelo de caja

    Todo elemento HTML se comporta como una caja rectangular con cuatro áreas diferenciadas, de dentro hacia fuera:

    flowchart TD
subgraph margin
  subgraph border
    subgraph padding      
      subgraph content
      end
    end
  end
end
    • Content: el área donde se muestra el texto, imagen u otro contenido del elemento.
    • Padding: espacio transparente entre el contenido y el borde.
    • Border: la línea que rodea el padding y el contenido.
    • Margin: espacio transparente alrededor del borde que separa el elemento de sus vecinos.

    Propiedades de la caja

    Las tres propiedades clave que controlan el tamaño y el espacio de la caja son:

    Propiedad Descripción
    width / height Define el tamaño del área de contenido
    padding Controla el espacio interno entre contenido y borde
    border Define el ancho, estilo y color del borde
    margin Controla el espacio externo entre el elemento y sus vecinos

    Ejemplo

    .caja {
  width: 200px;
  padding: 20px;
  border: 2px solid black;
  margin: 10px;
}

    El ancho total de esta caja en pantalla será: 200 + 20×2 + 2×2 + 10×2 = 264px.

    Nota: por defecto, el navegador aplica el modelo de caja content-box, donde width y height solo afectan al contenido. Con box-sizing: border-box, el padding y border se incluyen dentro del ancho y alto declarados.

    Inspector de elementos

    En el navegador, pulsando Ctrl + Shift + C puedes abrir el inspector de elementos de la página, te permite localizar el elemento html por el que pasas el ratón, y ver los valores que tienen cada uno de los elementos del modelo de caja.
