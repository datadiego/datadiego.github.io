    CSV

    CSV (Comma Separated Values) es un formato utilizado para almacenar tablas de datos en texto plano, es similar a lo que esperas de Excel o programas similares para trabajar con tablas.

    También suele ser común usarlas para exportar resultados de bases de datos y hacer análisis.

    Estructura

    Es bastante simple, la primera linea define los nombres de las columnas, luego los datos, cada elemento separado por una coma:

    id,nombre,edad,email
0,Diego,35,diego@gmail.com
1,Maria,22,maria@gmail.com
2,Manolo,52,manolo@gmail.com
3,Elvira,25,elvira@gmail.com

    Si representamos el csv anterior como una tabla:

    id nombre edad email
    0 Diego 35 diego@gmail.com
    1 Maria 22 maria@gmail.com
    2 Manolo 52 manolo@gmail.com
    3 Elvira 25 elvira@gmail.com

    La tabla tiene 4 columnas (id, nombre, edad y email) y 4 filas.

    Delimitador

    El delimitador estándar para estos archivos es la coma. Pero puede ser cualquiera, imagina una tabla para almacenar gatos y los colores de su pelo, si hacemos esto:

    nombre,sexo,colores
maraca,H,blanco,gris
salchichas,H,blanco,negro,naranja
mambo,M,negro,blanco
meowcifer,M,naranja

    ¿Como podemos distinguir los elementos de colores? En el header hemos definido tres columnas, pero la única fila que cumple esa condición es la última. El resto tienen más de una columna separada por comas.

    Si hacemos:

    nombre%sexo%colores
maraca%H%blanco,gris
salchichas%H%blanco,negro,naranja
mambo%M%negro,blanco
meowcifer%M%naranja

    Ahora si que podemos distinguir que separa una columna, y que separa los colores.

    Esto también sería valido:

    nombre,sexo,colores
maraca,H,blanco%gris
salchichas,H,blanco%negro%naranja
mambo,M,negro%blanco
meowcifer,M,naranja

    csvkit

    csvkit es un conjunto de herramientas que nos permiten analizar y modificar estos archivos.

    Vamos a utilizar el siguiente CSV para los ejemplos:

2,Manolo,52,manolo@gmail.com
3,Elvira,25,elvira@gmail.com

    csvsort

    Ordena según una columna, podemos usarla para ordenar por edad:

    ❯ csvsort -c edad usuarios.csv
id,nombre,edad,email
1,Maria,22,maria@gmail.com
4,Tomas,22,tomas@gmail.com
3,Elvira,25,elvira@gmail.com
0,Diego,35,diego@gmail.com
2,Manolo,52,manolo@gmail.com

    Invertir el orden con -r:

    ❯ csvsort -c edad -r usuarios.csv
id,nombre,edad,email
2,Manolo,52,manolo@gmail.com
0,Diego,35,diego@gmail.com
3,Elvira,25,elvira@gmail.com
1,Maria,22,maria@gmail.com
4,Tomas,22,tomas@gmail.com

    O por orden alfabetico en los nombres:

    ❯ csvsort -c nombre usuarios.csv
id,nombre,edad,email
0,Diego,35,diego@gmail.com
3,Elvira,25,elvira@gmail.com
2,Manolo,52,manolo@gmail.com
1,Maria,22,maria@gmail.com
4,Tomas,22,tomas@gmail.com

    csvgrep

    ❯ csvgrep -m "Elvira" -c nombre usuarios.csv

3,Elvira,25,elvira@gmail.com

❯ csvgrep -m "elvira" -c nombre usuarios.csv
id,nombre,edad,email

❯ csvgrep -m "22" -c edad usuarios.csv

1,Maria,22,maria@gmail.com
3,Tomas,22,tomas@gmail.com

❯ csvgrep -m "Ma" -c nombre usuarios.csv
id,nombre,edad,email
1,Maria,22,maria@gmail.com
2,Manolo,52,manolo@gmail.com

❯ csvgrep -r '[mM]a' -c nombre usuarios.csv

    csvsql

    Diferentes acciones para bases de datos y csv, por ejemplo, podemos crear una base de datos y un schema a partir del csv:

    ❯ csvsql --db sqlite:///usuarios.db --insert usuarios.csv

❯ sqlite3 usuarios.db ".dump" > schema.sql

    O hacer queries de SQL:

    ❯ csvsql --query "SELECT nombre FROM usuarios WHERE edad > 30" usuarios.csv
nombre
Diego
Manolo

    Pandas

    Pandas es una biblioteca de Python que proporciona estructuras de datos y herramientas de análisis de datos. Es especialmente útil para trabajar con datos tabulares, como los que se encuentran en archivos CSV. Para trabajar con archivos CSV en Pandas, puedes usar la función read_csv para leer el archivo y convertirlo en un DataFrame, que es una estructura de datos bidimensional similar a una tabla.

    import pandas as pd
usuarios = pd.read_csv('usuarios.csv')

print(usuarios)
print("--------------")
usuario_1 = usuarios[usuarios['id'] == 1]
print(usuario_1)
print("--------------")
usuarios_mayores_180 = usuarios[usuarios['saldo'] > 180]
print(usuarios_mayores_180)
print("--------------")
print(usuarios.columns)
print(usuarios.head())

    Acceder a los datos en un DataFrame es similar a trabajar con un diccionario, pero con la ventaja de que puedes usar tanto la notación de corchetes como la notación de punto para acceder a las columnas.

    print(usuarios['nombre'])  # Notación de corchetes
print(usuarios.nombre)      # Notación de punto

    Ademas de filtrar y seleccionar datos condicionalmente, Pandas permite realizar operaciones de agregación, ordenación...

    usuarios_ordenados = usuarios.sort_values(by='saldo', ascending=False)
print(usuarios_ordenados)
media_saldo = usuarios['saldo'].mean()
print(f"La media de saldo es: {media_saldo}")

    pandas es una herramienta muy poderosa para analisis de datos, big data y machine learning, es ampliamente utilizada en la comunidad de ciencia de datos, asi que dependiendo de tu proyecto, puede que necesites saberla.

    Ya hemos visto que al final, muchos datos se almacenan separandolos por algun caracter especial, vamos a crear un script que nos permita leer cualquier fichero plano, pasarle un delimitador y extraer los campos que nos interesen.

    #!/bin/bash
# Script para leer un fichero plano y extraer campos específicos
if [ "$#" -ne 3 ]; then
    echo "Uso: $0 <fichero> <delimitador> <campo1,campo2,...>"
    exit 1
fi

fichero="$1"
delimitador="$2"
campos="$3"
IFS="$delimitador" # Establece el delimitador

while read -r linea; do
    IFS="$delimitador" read -ra valores <<< "$linea" # Divide la línea en campos
    for campo in ${campos//,/ }; do
        echo -n "${valores[$campo]}$delimitador" # Imprime el campo solicitado
    done
    echo # Nueva línea al final de cada registro
done < "$fichero"
