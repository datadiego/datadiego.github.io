    MongoDB

    MongoDB es una base de datos NoSQL documental, los datos se guardan como JSON.

    Estructura

    Mongodb sigue la siguiente estructura para almacenar los datos:

    MongoDB
└── Base de datos
    └── Colección
        └── Documentos
            └── Campos

    Un documento dentro de la colección usuarios puede lucir asi:

    {
  "_id": "123",
  "nombre": "Ana",
  "edad": 28,
  "email": "ana@example.com",
  "intereses": ["programación", "música"]
}

    Consultas

    No puedes usar SQL, tendrás que usar una libreria que te permita interactuar con el servicio, puede variar la sintaxis dependiendo de que lenguaje uses, por ejemplo, en javascript:

    //SQL
//SELECT * FROM usuarios WHERE edad > 18;

//mongodb
db.usuarios.find({
  edad: { $gt: 18 }
})

    También puedes usar mongosh, el cliente de terminal para interactuar con la base de datos.

    Para descargar mongosh, sigue estas instrucciones

    Para instalar, descomprime con ❯ tar -xzf ~/Descargas/mongosh-2.10.0-linux-x64.tgz

    Luego, ejecuta el binario o copialo a un directorio en tu PATH como /usr/local/bin

    Entorno Docker

    Puedes levantar un entorno con mongodb con el siguiente docker-compose.yml:

    services:
  mongo:
    image: mongo
    restart: always
    ports: 
      - 27017:27017
    environment:
      MONGO_INITDB_ROOT_USERNAME: admin
      MONGO_INITDB_ROOT_PASSWORD: adminpass

  mongo-express:
    image: mongo-express
    restart: always
    ports:
      - 8081:8081
    environment:
      ME_CONFIG_MONGODB_URL: mongodb://admin:adminpass@mongo:27017/
      ME_CONFIG_BASICAUTH_ENABLED: true
      ME_CONFIG_BASICAUTH_USERNAME: admin
      ME_CONFIG_BASICAUTH_PASSWORD: adminpass

    Tendrás que recordar tu url:

    ME_CONFIG_MONGODB_URL: mongodb://admin:adminpass@mongo:27017/

    Conectándote a la base de datos

    Puedes hacerlo de varias formas:

    Desde tu host con mongosh

    Una vez lo tengas instalado o con el binario en tu sistema puedes conectarte con la URI del servicio:

    mongosh "mongodb://admin:@localhost:27017/?authSource=admin"

    Introduce tu contraseña de administración y estarás dentro

    Desde el contenedor

    Desde lazydocker puedes situarte en el contenedor de mongodb y pulsar E para obtener una shell dentro de tu contenedor, ahi tienes mongosh ya instalado, puedes entrar con el mismo comando que usaste previamente.

    Integración

    Puedes integrar mongodb con cualquier aplicación, en cualquier lenguaje, tendrás que descargar un driver que conecte, en bun por ejemplo:

    bun init
bun add mongodb

    Luego puedes conectarte con:

    import { MongoClient } from "mongodb";

const uri = process.env.MONGODB_URI ?? "mongodb://admin:adminpass@localhost:27017"
const client = new MongoClient(uri);

await client.connect();

const db = client.db("test");
await db.command({ ping: 1 });
console.log("Conectado a MongoDB");

await client.close();

    Recuerda usar variables de entorno o un archivo .env, el ejemplo anterior estás exponiendo en el propio código la contraseña de acceso a la base de datos.

    En bun es muy fácil, tu proyecto los lee automáticamente.

    Interactuando desde el CLI

    Vamos a realizar las acciones básicas que podemos esperar de una base de datos con mongosh:

    Crear una base de datos

    Utiliza use para entrar o crear en una base de datos:

    test> use probando
switched to db probando

    Insertar datos

    Utiliza db.nombre_db.insertOne() para insertar un objeto en la base de datos:

    probando> db.probando.insertOne({nombre: "Diego", edad: 35})
{
  acknowledged: true,
  insertedId: ObjectId('6aa58bd400a056e1bb0c9aac')
}

probando> db.probando.insertOne({nombre: "Elvira", edad: 22})
{
  acknowledged: true,
  insertedId: ObjectId('6aa58bdc00a056e1bb0c9aad')
}

    También puedes insertar múltiples objetos en un array con insertMany():

    probando> db.probando.insertMany([{val: "hola"}, {val: "adios"}])
{
  acknowledged: true,
  insertedIds: {
    '0': ObjectId('6aa58d4400a056e1bb0c9aae'),
    '1': ObjectId('6aa58d4400a056e1bb0c9aaf')
  }
}

    Fíjate como a la base de datos le da igual que documento estamos pasándole, no tiene ningún sistema que previene insertar datos que no son los correctos en una db concreta y no hay schema en ningún lado.

    Lee la documentación oficial sobre cómo insertar documentos para profundizar más.

    Leer datos

    Para extraer datos usamos db.nombre_db.find()

    probando> db.probando.find()
[
  {
    _id: ObjectId('6aa58bd400a056e1bb0c9aac'),
    nombre: 'Diego',
    edad: 35
  },
  {
    _id: ObjectId('6aa58bdc00a056e1bb0c9aad'),
    nombre: 'Elvira',
    edad: 22
  },
  { _id: ObjectId('6aa58d4400a056e1bb0c9aae'), val: 'hola' },
  { _id: ObjectId('6aa58d4400a056e1bb0c9aaf'), val: 'adios' }
]

    Tambien podemos filtrar pasando un objeto:

    probando> db.probando.find({edad: { $gt: 30}})
[
  {
    _id: ObjectId('6aa58bd400a056e1bb0c9aac'),
    nombre: 'Diego',
    edad: 35
  }
]

probando> db.probando.find({edad: { $lt: 30}})
[
  {
    _id: ObjectId('6aa58bdc00a056e1bb0c9aad'),
    nombre: 'Elvira',
    edad: 22
  }
]

    Y encontrar buscando claves concretas:

    probando> db.probando.find({val: {$exists: true}})
[
  { _id: ObjectId('6aa58d4400a056e1bb0c9aae'), val: 'hola' },
  { _id: ObjectId('6aa58d4400a056e1bb0c9aaf'), val: 'adios' }
]

    Lee la documentación oficial sobre cómo consultar documentos para profundizar más.

    También puedes encontrar más información de los operadores de consulta en la documentación oficial de mongodb.

    Actualizar un objeto

    Podemos modificar el valor de una clave con db.nombre_db.updateOne():

    probando> db.probando.updateOne({nombre: "Diego"}, {$set: {edad: 42}})
{
  acknowledged: true,
  insertedId: null,
  matchedCount: 1,
  modifiedCount: 1,
  upsertedCount: 0
}
probando> db.probando.find({nombre: "Diego"})
[
  {
    _id: ObjectId('6aa58bd400a056e1bb0c9aac'),
    nombre: 'Diego',
    edad: 42
  }
]

    También podemos modificar múltiples datos, y crear otros que no existian:

    probando> db.probando.updateOne(
| {_id: ObjectId("6aa58bd400a056e1bb0c9aac")},
| {
| $set: {
| nombre: "Diego Updated",
| edad: 33,
| ciudad: "Granada",
| email: "diego@gmail.com"
| }
| }
| )

{
  acknowledged: true,
  insertedId: null,
  matchedCount: 1,
  modifiedCount: 1,
  upsertedCount: 0
}

probando> db.probando.find({_id: ObjectId("6aa58bd400a056e1bb0c9aac")})
[
  {
    _id: ObjectId('6aa58bd400a056e1bb0c9aac'),
    nombre: 'Diego Updated',
    edad: 33,
    ciudad: 'Granada',
    email: 'diego@gmail.com'
  }
]

    Lee la documentación oficial sobre cómo actualizar documentos para profundizar más.

    Borrar un objeto

    Puedes usar db.nombre_db.findOneAndDelete() para eliminar entradas:

    probando> db.probando.findOneAndDelete({nombre: "Elvira"})
{
  _id: ObjectId('6aa58bdc00a056e1bb0c9aad'),
  nombre: 'Elvira',
  edad: 22
}
probando> db.probando.find({nombre: "Elvira"})

probando>
