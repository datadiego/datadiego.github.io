    Integraciones

    Integrar una base de datos en un proyecto de programación es bastante similar entre lenguajes y comparte conceptos ya vistos antes en la integración de sqlite con otros lenguajes.

    Java

    Para poder ejecutar/compilar java necesitarás java-25-openjdk-devel, y la librería que usa para conectar con mysql es mysql-connector-java, puedes instalar ambas desde el gestor de paquetes de Linux, o usar Maven/Gradle.

    import java.sql.*;

public class Main {
    public static void main(String[] args) throws Exception {
        listarGatitos();
    }

    static void listarGatitos() throws Exception {
        var conn = DriverManager.getConnection(
            "jdbc:mysql://xaphym:3306/home", 
            "datadiego", 
            "1234"
        );
        var rs = conn.createStatement().executeQuery("SELECT * FROM gatitos");
        while (rs.next()) {
            System.out.println(
                rs.getString("nombre") + " " + rs.getString("sexo")
            );
        }
        conn.close();
    }
}

    Luego, ejecutalo con:

    java -cp .:/usr/share/java/mysql-connector-java.jar Main.java

    Python

    En python necesitarás el paquete mysql-connector-python, usa uv o pip para instalarlo.

    uv init
uv add mysql-connector-python

    El código es muy simple y pythonico:

    import mysql.connector

CONFIG = {
    "host": "xaphym",
    "user": "datadiego",
    "password": "1234",
    "database": "home",
}


def main():
    connection = mysql.connector.connect(**CONFIG)
    try:
        cursor = connection.cursor()
        cursor.execute("SELECT * FROM gatitos")
        gatos = cursor.fetchall()
        print(gatos)
    finally:
        connection.close()


main()

    Bun

    Bun no necesita dependencias, tiene un driver nativo para conectar a múltiples motores de bases de datos:

    import { SQL } from "bun";

const sql = new SQL({
  adapter: "mysql",
  hostname: "xaphym",
  username: "datadiego",
  password: "1234",
  database: "home",
  allowPublicKeyRetrieval: true,
});

const rows = await sql`SELECT * FROM gatitos`;
console.log(rows);
await sql.close();

    Node

    Si usas Node, necesitarás mysql2/promise:

    import mysql from "mysql2/promise";

const conn = await mysql.createConnection({
  host: "xaphym",
  user: "datadiego",
  password: "1234",
  database: "home",
});

const [rows] = await conn.execute("SELECT * FROM gatitos");
console.log(rows);
await conn.end();
