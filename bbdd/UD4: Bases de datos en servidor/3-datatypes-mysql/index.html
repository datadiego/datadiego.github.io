    Datatypes en MySQL

    Al contrario que SQLite, MySQL si te obliga a dar el tipo de dato indicado en la definición de tu tabla:

    mysql> DESCRIBE test;
+--------+--------------+------+-----+---------+-------+
| Field  | Type         | Null | Key | Default | Extra |
+--------+--------------+------+-----+---------+-------+
| nombre | varchar(100) | YES  |     | NULL    |       |
| edad   | int          | YES  |     | NULL    |       |
+--------+--------------+------+-----+---------+-------+
2 rows in set (0,00 sec)

mysql> INSERT INTO test VALUES ('probando', 'hola');
ERROR 1366 (HY000): Incorrect integer value: 'hola' for column 'edad' at row 1

    Aun asi, intentará convertir valores al dato original siempre que pueda:

    mysql> INSERT INTO test VALUES ('probando', '123');
Query OK, 1 row affected (0,01 sec)

    En este motor tenemos muchos mas tipos de datos que los que ofrece SQLite.

    Puedes ver todos los tipos de datos que puedes usar en detalle en la documentacion oficial

    Datos numéricos

    Enteros

    Dispones de varios tamaños:

    CREATE TABLE enteros (
  tiny_s      TINYINT,          -- (-128 a 127)
  tiny_u      TINYINT UNSIGNED, -- (0 a 255)
  small_s     SMALLINT,         -- (-32 768 a 32 767)
  small_u     SMALLINT UNSIGNED,-- (0 a 65 535)
  medium_s    MEDIUMINT,        -- (-8 388 608 a 8 388 607)
  medium_u    MEDIUMINT UNSIGNED,-- (0 a 16 777 215)
  big_s       BIGINT,           -- (-9.2e18 a 9.2e18)
  big_u       BIGINT UNSIGNED   -- (0 a 1.8e19)
);

    Decimales

    Al igual que en los enteros, dispones de varios tamaños predefinidos (float y double), y decimal para indicar cuantos decimales quieres almacenar:

    CREATE TABLE decimales (
  etiqueta  VARCHAR(30),
  f         FLOAT,           -- 4 bytes, ~7 decimales de precision
  d         DOUBLE,          -- 8 bytes, ~15 decimales de precision
  dec10_2   DECIMAL(10,2),   -- exacto: 8 enteros + 2 decimales
  dec5_4    DECIMAL(5,4)     -- exacto: 1 entero  + 4 decimales
);

    Texto

    En texto también disponemos de varios tamaños, debemos reservar algunos bytes para almacenar la longitud del string.

    CREATE TABLE textos (
  c10        CHAR(10),        -- siempre ocupa 10 chars (rellena con espacios)
  v50        VARCHAR(50),     -- ocupa solo lo necesario + 1 byte de longitud
  tiny_txt   TINYTEXT,        -- hasta 255 chars  + 1 byte
  txt        TEXT,            -- hasta 65 535 chars + 2 bytes
  med_txt    MEDIUMTEXT,      -- hasta 16M chars + 3 bytes
  long_txt   LONGTEXT         -- hasta 4G chars + 4 bytes
);

    Conjuntos

    Podemos almacenar una lista de valores posibles:

    CREATE TABLE enums_sets (
  dias     SET('lun','mar','mie','jue','vie','sab','dom'),
  estado   ENUM('activo','inactivo','pendiente')
);

INSERT INTO enums_sets VALUES ('lun,mar,mie', 'activo');

    SET permite insertar múltiples valores de la lista dada en la definición, ENUM solo permite un valor de la lista.

    Fechas

    CREATE TABLE fechas_horas (
  id        INT AUTO_INCREMENT PRIMARY KEY,
  etiqueta  VARCHAR(30),
  f_date    DATE,              -- solo fecha: 1000-01-01 a 9999-12-31
  f_time    TIME,              -- solo hora: -838:59:59 a 838:59:59
  f_dt      DATETIME,          -- fecha+hora, rango 1000..9999
  f_ts      TIMESTAMP,         -- fecha+hora, rango 1970..2038, se actualiza con zona
  f_year    YEAR               -- solo año: 1901 a 2155
);

    Si quieres una columna para que registre el momento en el que se introduce un dato:

    CREATE TABLE tabla (
  id INT AUTO_INCREMENT PRIMARY KEY,
  nombre VARCHAR(100),
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

    Booleanos

    Valores true y false:

    CREATE TABLE booleanos (
  id      INT AUTO_INCREMENT PRIMARY KEY,
  activo  BOOLEAN,   -- alias de TINYINT(1): TRUE=1, FALSE=0
  verificado BOOLEAN DEFAULT FALSE
);

INSERT INTO booleanos (activo, verificado) VALUES
(TRUE,FALSE),
(FALSE,TRUE),
(1,0),
(NULL,NULL);

    Binarios

    Utiles para almacenar imágenes y otros tipos de datos complejos:

    CREATE TABLE binarios (
  etiqueta  VARCHAR(30),
  b5        BINARY(5),        -- fijo 5 bytes, rellena con 0x00
  vb10      VARBINARY(10),    -- variable hasta 10 bytes
  tinyblob  TINYBLOB,         -- hasta 255 bytes
  blob_data BLOB              -- hasta 65 535 bytes
);

INSERT INTO binarios (etiqueta, b5, vb10, tinyblob, blob_data) VALUES
('ascii','abc','abc','binario1','contenido grande'),
('hex',0xAABB,0xAABBCC,0xFF,0xDEADBEEF),
('mixto','hello','hello',0x01020304,0x0011223344);

    JSON

    Puedes almacenar JSON dentro de una tabla:

    CREATE TABLE json_data (
  id       INT AUTO_INCREMENT PRIMARY KEY,
  config   JSON
);

INSERT INTO json_data (config) VALUES
('{"color": "rojo", "place": "top"}'),
('{"color": "verde", "place": "bottom"}'),
('{"color": "azul", "place": "right"}');

    Y seleccionar valores dentro del mismo:

    mysql> select config->'$.color' from json_data;
+-------------------+
| config->'$.color' |
+-------------------+
| "rojo"            |
| "verde"           |
| "azul"            |
+-------------------+
3 rows in set (0,00 sec)
