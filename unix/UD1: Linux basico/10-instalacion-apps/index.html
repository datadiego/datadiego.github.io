    Otras formas de instalar aplicaciones

    Hasta ahora has usado tu gestor de paquetes para instalar aplicaciones, si bien los repositorios de tu distro tienen muchas apps, lo más seguro es que tarde o temprano des con alguna que no está ahí.

    Eso no significa que no puedes instalarla, en Linux tenemos múltiples formas de instalar aplicaciones, cada una con diferentes aspectos a tener en cuenta.

    Formas de instalar aplicaciones

    En cualquier distribución de Linux, puedes instalar aplicaciones de varias maneras:

    • A través del gestor de paquetes: Usando el gestor de paquetes de tu distribución (por ejemplo, apt, yum, dnf).
    • Descargando el paquete: Descargando el paquete .deb o .rpm directamente desde el sitio web del desarrollador.
    • Compilando desde el código fuente: Descargando el código fuente y compilándolo en tu sistema.
    • Flatpak: Usando el gestor de paquetes Flatpak para instalar aplicaciones en Linux.
    • Snap: Usando el gestor de paquetes Snap para instalar aplicaciones en Linux.
    • Scripts: Muchos desarrolladores publican scripts para instalar aplicaciones en Linux.

    Cada una tiene sus propias ventajas y desventajas, que iremos viendo en detalle.

    Descargando el paquete

    Muchas veces, un paquete no está disponible en el gestor de paquetes, pero sí en el sitio web del desarrollador en formato .deb(para Debian/Ubuntu) o .rpm(para Fedora/Red Hat).

    Solo tienes que descargar el paquete y usar el gestor de paquetes correspondiente para instalarlo, por ejemplo:

    sudo dpkg -i <ruta_del_paquete>.deb

    sudo rpm install <ruta_del_paquete>.rpm

    No olvides reemplazar <ruta_del_paquete> con la ruta real del paquete que deseas instalar. Generalmente lo tendrás en tu directorio de descargas.

    Instalación a través de scripts

    Muchas veces, los desarrolladores publican scripts para instalar aplicaciones en Linux. Estos scripts suelen ser más simples y fáciles de usar que los paquetes tradicionales. Solo tienes que copiarlos y ejecutarlos en tu terminal.

    Es el caso de zed, por ejemplo.

    Instalación a través de Flatpak

    Flatpak es universal y no depende de la distribución de Linux.

    Primero necesitas instalar Flatpak desde el gestor de paquetes de tu distribución:

    sudo apt install flatpak
sudo dnf install flatpak

    Luego puedes entrar a Flathub para buscar y descargar aplicaciones Flatpak.

    Para ejecutarlas, simplemente usa el comando flatpak run seguido del nombre del paquete:

    flatpak run <nombre_del_paquete>

    Snap

    Snap es otro gestor de paquetes universal que no depende de la distribución de Linux.

    Instalar Snap es similar a Flatpak:

    sudo apt install snapd
sudo dnf install snapd

    Luego puedes buscar y descargar aplicaciones Snap desde Snapcraft.

    Instalar una aplicación Snap es similar a Flatpak:

    snap install <nombre_del_paquete>

    Y puedes ejecutarla con:

    snap run <nombre_del_paquete>

    Binario

    En ocasiones encontrarás repositorios que proporcionan binarios precompilados para tu distribución.

    Por ejemplo, tetrotui ofrece binarios en la seccion de releases.

    Solo tienes que descargar el binario, descomprimirlo, darle permisos de ejecución y ejecutarlo:

    chmod +x <nombre_del_binario>
./<nombre_del_binario>

    Puedes automatizar esta tarea:

    URL="https://github.com/Strophox/tetro-tui/releases/download/v3.1.0/tetro-tui_v3.1_x86_64-unknown-linux-gnu.zip"
TMP_DIR="$(mktemp -d)"
wget -q "$URL" -O "$TMP_DIR/tetro.zip"
unzip -q "$TMP_DIR/tetro.zip" -d "$TMP_DIR"
chmod +x "$TMP_DIR/tetro-tui"
sudo mv "$TMP_DIR/tetro-tui" /usr/local/bin/tetro-tui

    Desde código fuente

    Muchas aplicaciones también se pueden instalar desde el código fuente. Esto requiere habilidades técnicas y puede ser más complejo, pero es una opción valiosa cuando no hay paquetes disponibles para tu distribución.
