    Comandos I

    Busca la terminal en tu launcher de aplicaciones y ejecútala, vamos a ver como usar la terminal.

    Sobre el miedo a la terminal

    La terminal es una interfaz que te permite interactuar con tu equipo lanzando comandos de texto. De primeras puede sentirse como algo obsoleto y complejo.

    Muchos usuarios suelen tener miedo a Linux por la terminal. La realidad es que la mayoría de distros pueden usarse sin tener que pasar por la terminal para un uso básico. Puedes instalar software, configurar tu equipo y ejecutar aplicaciones sin necesidad de usarla.

    Mi madre usa gnome desde hace años, nunca ha tenido que abrir una terminal.

    Ventajas de usar la terminal

    Aprender a usarla te va a aportar varias ventajas:

    • Más eficaz a la hora de realizar acciones, para la mayoría de tareas es más rápida.
    • Hay cosas que simplemente no se pueden hacer mediante una interfaz, o al menos no de una manera tan cómoda.
    • Podrás modificar mucho más cómo el sistema debe responder, y qué quieres que haga.
    • Automatizar tareas repetitivas de manera simple.
    • Poder usar agentes de IA de manera más eficaz.

    Además, este tipo de interfaz tiene una ventaja sobre usar una interfaz gráfica. Puedes compartir comandos, problemas y soluciones mucho más fácil.

    Si usas una interfaz gráfica vas a tener que describir todo el problema, a que menú fuiste, donde hiciste click, en que caja escribiste algo o que opciones activaste, incluso compartir screenshots o videos.

    Como muestra de esto último, el tutorial que seguiste anteriormente para montar la VM ha requerido 16 imágenes. El resto del curso en dos materias ninguna, solo comandos de terminal en su mayoría.

    La solución será igual de complicada, tendrán que guiarte a que menu debes ir, donde pulsar, que opciones configurar.

    Con terminal, simplemente puedes plantear tu duda, por ejemplo:

    Estoy siguiendo una guia sobre linux, intento crear un archivo y leerlo pero me da error, además no aparece en la carpeta donde estoy, estos son los pasos que he seguido:

    ~/pruebas
❯ echo "hola mundo" > .holamundo.txt

~/pruebas
❯ cat holamundo.txt
cat: holamundo.txt: No existe el fichero o el directorio

~/pruebas
❯ ls

    Y un usuario responder:

    Tuviste un error muy tonto, has creado el archivo con el nombre .holamundo.txt, los archivos que empiezan por . son archivos ocultos, puedes usar ls -la para verlos:

    ~/pruebas
❯ echo "hola mundo" > .holamundo.txt

~/pruebas
❯ ls -la
.rw-r--r--@ 11 datadiego 16 sep 16:44 .holamundo.txt

~/pruebas
❯ cat .holamundo.txt
hola mundo

    Quizá intentabas hacer esto:

    ~/pruebas
❯ echo "hola mundo" > ./holamundo.txt

~/pruebas
❯ cat holamundo.txt
hola mundo

~/pruebas
❯ ls
.rw-r--r--@ 11 datadiego 16 sep 16:45 holamundo.txt

    Aqui ./ se refiere a crear el archivo en este directorio, aunque puedes obviarlo y simplemente hacer:

    ~/pruebas
❯ echo "hola mundo" > holamundo.txt

~/pruebas
❯ ls
.rw-r--r--@ 11 datadiego 16 sep 16:46 holamundo.txt

    Tus primeros comandos

    Cuando abras la terminal verás tu prompt, está esperando que escribas algo y pulses enter:

    ❯ socorro
bash: socorro: instrucción no encontrada...

    Si introduces un comando que no existe dará error.

    pwd

    Un comando muy simple, te dice donde estás situado en el sistema de archivos ahora mismo, la terminal puede moverse entre directorios igual que harías desde el gestor de archivos.

    ❯ pwd
/home/datadiego

    Por defecto, cuando abres tu terminal estarás en tu home, este es el directorio de tu usuario. Similar a esto en Windows:

    C:\Users\Diego\

    ls

    Te muestra que hay donde estás situado:

    ❯ ls
 Descargas    Escritorio   Música   Documentos
 Imágenes       Vídeos

    Añadiendo flags a comandos

    A muchos comandos podemos añadir flags, opciones extra que modifican el comportamiento del comando, o en muchas ocasiones son necesarias para que funcione.

    Vamos a probar a añadir la flag -l a nuestro comando:

    ❯ ls -l
total 0
drwxr-xr-x. 1 datadiego datadiego 2458 sep 16 19:43  Descargas
drwxr-xr-x. 1 datadiego datadiego  250 sep 16 10:03  Documentos
drwxr-xr-x. 1 datadiego datadiego    0 ago 25 09:18  Escritorio
drwxr-xr-x. 1 datadiego datadiego  320 sep 15 21:23  Imágenes
drwxr-xr-x. 1 datadiego datadiego    0 ago 25 09:18  Música
drwxr-xr-x. 1 datadiego datadiego    0 ago 25 09:18  Vídeos

    Ahora nos muestra más información y los presenta en formato lista.

    Mostrando todos los archivos

    Los archivos y directorios que empiezan por . están ocultos, puedes verlos con ls -a.

    Además, puedes combinarlo con la flag anterior, tanto ls -l -a como ls -la son válidos.

    echo

    Comando bastante simple, pero en ocasiones útil, como veremos más adelante, devuelve el texto que escribamos:

    ~
❯ echo 'hola mundo'
hola mundo

~
❯ echo "hola linux"
hola linux

    Tambien puedes usarlo para crear un archivo usando una redirección:

    ~/Escritorio
❯ echo "hola mundo" > holamundo.txt

~/Escritorio
❯ ls
.rw-r--r--@ 11 datadiego 17 sep 20:41 holamundo.txt

    cd

    Nos permite cambiar de directorio indicando una ruta:

    ~
❯ ls
drwxr-xr-x@ - datadiego 16 sep 19:43 Descargas
drwxr-xr-x@ - datadiego 16 sep 10:03 Documentos
drwxr-xr-x@ - datadiego 25 ago 09:18 Escritorio
drwxr-xr-x@ - datadiego 15 sep 21:23 Imágenes
drwxr-xr-x@ - datadiego 25 ago 09:18 Música
drwxr-xr-x@ - datadiego 25 ago 09:18 Vídeos

~
❯ cd Escritorio/

~/Escritorio
❯

    Si lanzas cd sin ninguna ruta, te devuelve a tu home:

    ~/Escritorio
❯ pwd
/home/datadiego/Escritorio

~/Escritorio
❯ cd

~
❯ pwd
/home/datadiego

    Rutas

    Una ruta es el camino que debe seguir tu sistema para llegar hasta un directorio o archivo.

    Existen dos tipos de rutas

    Relativas

    Una ruta que tiene en cuenta donde estás situado en este momento, por ejemplo:

    ~
❯ pwd
/home/datadiego

~
❯ ls
drwxr-xr-x@ - datadiego 16 sep 19:43 Descargas
drwxr-xr-x@ - datadiego 16 sep 10:03 Documentos
drwxr-xr-x@ - datadiego 25 ago 09:18 Escritorio
drwxr-xr-x@ - datadiego 15 sep 21:23 Imágenes
drwxr-xr-x@ - datadiego 25 ago 09:18 Música
drwxr-xr-x@ - datadiego 25 ago 09:18 Vídeos

~
❯ cd Escritorio/

~/Escritorio
❯ pwd
/home/datadiego/Escritorio

    Al mirar con ls hemos podido ver donde podemos movernos directamente, piensa en una ruta relativa cómo en una habitación contigua a la que entras por una puerta.

    Absoluta

    Una ruta que empieza desde la raiz del sistema / y describe por donde debe ir hasta llegar a un directorio, el ejemplo anterior con una ruta absoluta sería:

    ~
❯ pwd
/home/datadiego

~
❯ cd /home/datadiego/Escritorio/

    Si antes comparábamos movernos usando rutas relativas con entrar por una puerta, movernos con rutas absolutas te permite teletransportarte a cualquier sitio, independientemente de si el directorio está en una habitación contigua:

    ~/Escritorio
❯ pwd
/home/datadiego/Escritorio

~/Escritorio
❯ cd /home/datadiego/Descargas/

    Para llegar a Descargas desde nuestro escritorio con rutas relativas tendríamos que haber hecho:

    ~/Escritorio
❯ pwd
/home/datadiego/Escritorio

~/Escritorio
❯ cd ..

~
❯ pwd
/home/datadiego

~
❯ cd Descargas/

~/Descargas
❯ pwd
/home/datadiego/Descargas

    Autocompletado

    Linux puede autocompletar rutas cuando estás escribiendo comandos, prueba a escribir cd, poner un espacio y pulsar tabulador:

    ~
❯ cd 
Descargas/   Escritorio/  Música/  Vídeos/
Documentos/  Imágenes/

    Te mostrará donde puedes moverte donde estás situado.

    Tampoco tienes por qué escribir todo el nombre de un directorio cuando te mueves a el, si pones cd Esc y tabulas, se completará.

    Usa esto TODO el rato, el tabulador no solo te ahorra tiempo, también te confirma que donde vas existe, si escribes un directorio o archivo que no existe y tabulas, nunca completará la palabra

    Otras formas de moverse

    cd .. te lleva al directorio superior en la estructura de archivos:

    ~
❯ pwd
/home/datadiego

~
❯ cd Descargas/

~/Descargas
❯ cd ..

~
❯ pwd
/home/datadiego

    cd - te lleva al directorio anterior en el tiempo, no importa donde esté:

    ~
❯ cd Descargas/

~/Descargas
❯ cd ../Escritorio/

~/Escritorio
❯ cd -

~/Descargas
❯ pwd
/home/datadiego/Descargas

    mkdir

    Nos permite crear directorios:

    ~
❯ mkdir prueba

~
❯ ls
drwxr-xr-x@ - datadiego 16 sep 19:43 Descargas
drwxr-xr-x@ - datadiego 16 sep 10:03 Documentos
drwxr-xr-x@ - datadiego 25 ago 09:18 Escritorio
drwxr-xr-x@ - datadiego 15 sep 21:23 Imágenes
drwxr-xr-x@ - datadiego 25 ago 09:18 Música
drwxr-xr-x@ - datadiego 16 sep 20:41 prueba
drwxr-xr-x@ - datadiego 25 ago 09:18 Vídeos

~
❯ cd prueba/

~/prueba
❯

    Podemos usar mkdir -p para crear una estructura de directorios completa:

    ~/prueba
❯ mkdir proyecto/media/imagenes
mkdir: no se puede crear el directorio «proyecto/media/imagenes»: No existe el fichero o el directorio

~/prueba
❯ mkdir proyecto/media/imagenes -p

~/prueba
❯ ls
drwxr-xr-x@ - datadiego 16 sep 20:43 proyecto

~/prueba
❯ cd proyecto/

~/prueba/proyecto
❯ ls
drwxr-xr-x@ - datadiego 16 sep 20:43 media

~/prueba/proyecto
❯ cd media/

prueba/proyecto/media
❯ ls
drwxr-xr-x@ - datadiego 16 sep 20:43 imagenes

prueba/proyecto/media
❯ cd imagenes/

proyecto/media/imagenes
❯

    En el ejemplo hemos creado la siguiente estructura dentro de ~/prueba:

    prueba
└── proyecto
    └── media
        └── imagenes

    nano

    nano es un editor de texto en terminal que viene instalado en la mayoría de distribuciones, podemos crear cualquier archivo con nano <nombre_archivo>:

    ~/prueba
❯ nano holamundo.txt

    Esto abrirá un editor en el que podemos escribir nuestro documento.

    Para guardarlo pulsa Ctrl + x, confirma con S o Y según te indiquen abajo, y finalmente modifica (si quieres) el nombre del archivo que estás editando, si no lo quieres editar, pulsa enter.

    cat

    Sirve para leer archivos:

    ~/prueba
❯ ls
.rw-r--r--@ 11 datadiego 16 sep 20:50 holamundo.txt
drwxr-xr-x@  - datadiego 16 sep 20:43 proyecto

~/prueba
❯ cat holamundo.txt
hola linux

    Recuerda que puedes usar echo junto a una redirección para hacer archivos simples en estas pruebas iniciales:

    ~/Escritorio
❯ echo "mi texto" > archivo

~/Escritorio
❯ cat archivo
mi texto

    rm

    Te permite borrar archivos:

    ~/prueba
❯ cat holamundo.txt
hola linux

~/prueba
❯ rm holamundo.txt

~/prueba
❯ cat holamundo.txt
cat: holamundo.txt: No existe el fichero o el directorio

    Y directorios con la flag -fr:

    ~/prueba
❯ tree .
.
└── proyecto
    └── media
        └── imagenes

4 directories, 0 files

~/prueba
❯ ls
drwxr-xr-x@ - datadiego 16 sep 20:43 proyecto

~/prueba
❯ rm -rf proyecto/

~/prueba
❯ ls

    Finalizando

    Con esto tienes más que de sobra para empezar a practicar el uso de la terminal.

    Son comandos que hacen cosas simples, pero que se usan a diario.
