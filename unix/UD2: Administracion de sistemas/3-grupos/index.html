    Grupos

    Los grupos son una forma de organizar usuarios y qué pueden hacer con determinados archivos y directorios del sistema.

    Ver a que grupos perteneces

    Usa groups para ver los grupos a los que pertenece un usuario:

    ~
❯ groups
datadiego wheel docker

~
❯ su pruebas
pruebas@fedora:/home/datadiego$ groups
pruebas

    Cada usuario tiene su propio grupo, y puede estar en otros, datadiego pertenece a wheel y a docker, lo que le da acceso a sudo y docker

    wheel

    El grupo wheel es muy importante y peligroso.

    Sin el grupo wheel, un usuario no tiene acceso de administración, por ejemplo, el usuario pruebas no puede instalar aplicaciones nuevas:

    pruebas@fedora:~$ sudo dnf install tor
[sudo] contraseña para pruebas:
pruebas is not in the sudoers file.

    Añadir usuarios a un grupo

    Para añadir usuarios a un grupo, utiliza usermod -aG grupo usuario, por ejemplo:

    ❯ sudo usermod -aG wheel pruebas
[sudo] contraseña para datadiego:

~ took 7s
❯ su pruebas
Contraseña:
pruebas@fedora:/home/datadiego$ sudo dnf install figlet
[sudo] contraseña para pruebas:
Actualizando y cargando repositorios:

    Eliminar usuarios de un grupo

    Usa gpasswd -d usuario grupo para sacar de un grupo a un usuario:

    ~ took 26s
❯ sudo gpasswd -d pruebas wheel
Eliminando al usuario pruebas del grupo wheel

    No dejes este usuario con permisos de sudo

    Crear grupos

    Puedes crear grupos con groupadd grupo, por ejemplo:

    ~
❯ groups
datadiego wheel docker

~
❯ sudo groupadd developers

~
❯ sudo usermod -aG developers datadiego

    Los cambios no surtirán efecto hasta que cierres sesión y vuelvas a iniciarla

    Durante el curso no tendrás que crear grupos ni gestionarlos, pero muy ocasionalmente tendrás que añadir tu usuario a grupos para usar algunas herramientas.
