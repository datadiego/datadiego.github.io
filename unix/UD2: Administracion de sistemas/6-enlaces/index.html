    Enlaces

    Ya sabes crear archivos, y moverlos o copiarlos en tu sistema, otro concepto importante son los enlaces simbólicos.

    Preparando el laboratorio

    Vamos a crear un directorio en /tmp para experimentar con enlaces.

    Dentro, crea otros dos directorios:

    /tmp/test
❯ tree .
.
├── dirA
└── dirB

    Por ultimo, crea un archivo con algun texto:

    echo "hola mundo" > hello.txt

    Nos quedamos con esto en el directorio:

    .
├── dirA
├── dirB
└── hello.txt

    Creando un enlace simbólico

    Podemos crear enlaces simbolicos con ln:

    /tmp/test
❯ ln -s /tmp/test/hello.txt /tmp/test/dirA/

/tmp/test
❯ cat dirA/hello.txt
hola mundo

    Recuerda que debes usar rutas absolutas para crearlo correctamente.

    Hasta ahora, el enlace simbólico parece simplemente una copia del archivo original, pero si hacemos ls:

    /tmp/test
❯ ls dirA
lrwxrwxrwx@ - datadiego 18 sep 22:49 hello.txt -> /tmp/test/hello.txt

    La parte final hello.txt -> /tmp/test/hello.txt nos indica que ambos archivos son el mismo, si editamos cualquiera de ellos, el otro se modifica también:

    /tmp/test
❯ echo "un cambio" > hello.txt

/tmp/test
❯ cat dirA/hello.txt
un cambio

/tmp/test
❯ echo "otro cambio" > dirA/hello.txt

/tmp/test
❯ cat hello.txt
otro cambio

    Borralos como cualquier otro archivo:

    /tmp/test
❯ rm dirA/hello.txt

/tmp/test
❯ ls dirA

    Si en lugar de borrar el enlace, borras el archivo de origen, el enlace se rompe:

    /tmp/test
❯ ln -s /tmp/test/hello.txt /tmp/test/dirA/

/tmp/test
❯ cat dirA/hello.txt
hola mundo

/tmp/test
❯ rm hello.txt

/tmp/test
❯ ls dirA
lrwxrwxrwx@ - datadiego 18 sep 22:59 hello.txt -> /tmp/test/hello.txt

/tmp/test
❯ cat dirA/hello.txt
cat: dirA/hello.txt: No existe el fichero o el directorio

    Creando un enlace duro

    Los enlaces duros son similares a la hora de crearlos:

    /tmp/test
❯ echo "hola mundo" > hello.txt

/tmp/test
❯ ln /tmp/test/hello.txt /tmp/test/dirB/

/tmp/test
❯ cat dirB/hello.txt
hola mundo

/tmp/test
❯ rm hello.txt

/tmp/test
❯ cat dirB/hello.txt
hola mundo

    Como ves, en este caso si borramos el origen, el enlace de destino continúa existiendo.

    Cuando usarlos

    Los enlaces tienen diferentes usos, quizá no los crearás todos los dias, pero muchas veces te facilitarán la vida.

    Por ejemplo, muchos servidores web y otros servicios estan en directorios a los que solo podemos acceder con root, como /var/www/. Editar archivos ahí es tedioso porque no podemos hacerlo con nuestro usuario, pero podemos crear un enlace simbólico al directorio donde tenemos nuestro proyecto web hasta ese directorio, y trabajar sin andar haciendo sudo.

    En la unidad de Gestión de dotfiles verás un uso muy bueno de este concepto.
