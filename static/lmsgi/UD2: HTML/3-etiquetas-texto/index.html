    Etiquetas de texto

    HTML ofrece multitud de etiquetas para estructurar y dar formato al contenido textual de nuestras páginas.

    Encabezados

    Las etiquetas de encabezado van desde <h1> hasta <h6>, siendo <h1> el de mayor nivel jerárquico y <h6> el de menor.

    <h1>Encabezado nivel 1</h1>
<h2>Encabezado nivel 2</h2>
<h3>Encabezado nivel 3</h3>
<h4>Encabezado nivel 4</h4>
<h5>Encabezado nivel 5</h5>
<h6>Encabezado nivel 6</h6>

    Es importante mantener una jerarquía coherente. No se debe saltar de <h1> a <h3> sin pasar por <h2>.

    Párrafos

    La etiqueta <p> define un párrafo de texto. El navegador añade automáticamente un espacio antes y después de cada párrafo.

    <p>Este es el primer párrafo.</p>
<p>Este es el segundo párrafo.</p>

    Formato de texto

    HTML proporciona varias etiquetas para dar formato al texto sin cambiar su significado semántico:

    <p>Texto en <strong>negrita</strong></p>
<p>Texto en <em>cursiva</em></p>
<p>Texto en <u>subrayado</u></p>
<p>Texto en <s>tachado</s></p>
<p>Texto en <mark>resaltado</mark></p>
<p>Texto en <small>pequeño</small></p>
<p>Texto en <sub>subíndice</sub></p>
<p>Texto en <sup>superíndice</sup></p>
    Etiqueta Uso
    <strong> Importancia fuerte (negrita semántica)
    <em> Énfasis (cursiva semántica)
    <b> Negrita visual sin énfasis semántico
    <i> Cursiva visual sin énfasis semántico
    <u> Subrayado
    <s> Texto tachado (ya no relevante)
    <mark> Texto resaltado
    <small> Texto de tamaño menor
    <sub> Subíndice
    <sup> Superíndice

    Saltos de línea

    La etiqueta <br> inserta un salto de línea simple, sin abrir un nuevo párrafo.

    <p>Primera línea<br>Segunda línea<br>Tercera línea</p>

    En texto no es tan usado, pero muchos elementos como botones y otros inputs para el usuario suelen aparecer en la misma linea, <br> es una forma rápida de moverlos a una nueva linea.

    Línea horizontal

    La etiqueta <hr> inserta una línea horizontal que funciona como separador temático.

    <p>Sección 1</p>
<hr>
<p>Sección 2</p>

    Enlaces

    La etiqueta <a> (anchor) crea hipervínculos a otros recursos, páginas o ubicaciones dentro del mismo documento.

    Recursos externos

    Enlace a una página web externa:

    <a href="https://www.google.com" target="_blank" rel="noopener noreferrer">Ir a Google</a>

    target="_blank" abre el enlace en una nueva pestaña. rel="noopener noreferrer" previene vulnerabilidades de seguridad al abrir enlaces externos.

    Recursos del servidor

    Enlace a un archivo alojado en el mismo servidor:

    <a href="/documentos/manual.pdf">Descargar manual</a>
<a href="imagenes/foto.jpg">Ver imagen</a>

    Enlaces dentro del documento

    Enlace a una sección de la misma página mediante un id:

    <!-- Enlace -->
<a href="#seccion-contacto">Ir a contacto</a>

<!-- Destino -->
<section id="seccion-contacto">
  <h2>Contacto</h2>
  <p>Información de contacto...</p>
</section>

    Atributos del <a>

    Atributo Uso
    href URL de destino del enlace
    target _blank (nueva pestaña), _self (misma pestaña, por defecto)
    rel Relación con el documento destino (noopener, noreferrer, nofollow)
    title Texto informativo al pasar el cursor sobre el enlace

    Citas

    Cita en bloque

    La etiqueta <blockquote> se utiliza para citas largas que ocupan varias líneas.

    <blockquote>
  <p>La vida es lo que te pasa mientras estás ocupado haciendo otros planes.</p>
</blockquote>

    Código

    Para mostrar código fuente o fragmentos de código, HTML ofrece dos opciones:

    <p>Usa la etiqueta <code>code</code> para código en línea.</p>

<pre><code>function saludar() {
  console.log("Hola mundo");
}</code></pre>

    También tenemos etiquetas para combinaciones de teclado <kbd> y para resultados de un comando con <samp>:

    <p>Presiona <kbd>Ctrl</kbd> + <kbd>S</kbd> para guardar.</p>
<p><samp>Error: archivo no encontrado</samp></p>

    Listas

    Lista desordenada

    Elementos que no necesitan un orden determinado:

    <ul>
  <li>Elemento 1</li>
  <li>Elemento 2</li>
  <li>Elemento 3</li>
</ul>

    Lista ordenada

    Elementos que necesitan un orden concreto:

    <ol>
  <li>Primer paso</li>
  <li>Segundo paso</li>
  <li>Tercer paso</li>
</ol>

    Lista de definición

    Para elementos que contienen un termino y una descripción, como un diccionario.

    <dl>
  <dt>HTML</dt>
  <dd>Lenguaje de marcado para estructurar contenido web.</dd>

  <dt>CSS</dt>
  <dd>Lenguaje de estilos para diseñar la apariencia visual.</dd>
</dl>
