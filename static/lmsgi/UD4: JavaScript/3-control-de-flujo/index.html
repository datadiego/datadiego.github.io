    Control de flujo

    El control de flujo define el orden en el que se ejecutan las instrucciones de un programa. Por defecto, JavaScript ejecuta el código de arriba a abajo, pero con ciertas estructuras podemos tomar decisiones o repetir bloques de código.

    Existen dos grandes grupos:

    • Condicionales: ejecutan un bloque de código solo si se cumple una condición (if, else, switch).
    • Bucles: repiten un bloque de código mientras se cumpla una condición (for, while, do while).

    Valores verdaderos y falsos

    Antes de ver los condicionales, hay que entender un concepto clave: cualquier valor en JavaScript se puede evaluar como true o false cuando lo usamos en una condición.

    Se denominan truthy (que se evalúa como verdadero) y falsy (que se evalúa como falso).

    Solo hay unos pocos valores falsy:

    false
0
""        // string vacío
null
undefined
NaN

    Todo lo demás es truthy, incluidos los arrays vacíos [], los objetos vacíos {} y el string " " (con espacio).

    if ("Hola")        console.log("truthy")
if (42)            console.log("truthy")
if ([])            console.log("truthy")   // array vacío
if ({})            console.log("truthy")   // objeto vacío
if ("")            console.log("..." )     // nunca se ejecuta (falsy)
if (0)             console.log("..." )     // nunca se ejecuta (falsy)

    if / else

    La estructura más básica. Ejecuta un bloque de código solo si la condición es verdadera.

    let edad = 18;

if (edad >= 18) {
  console.log("Eres mayor de edad");
}

    Con else ejecutamos un bloque alternativo cuando la condición es falsa:

    let edad = 16;

if (edad >= 18) {
  console.log("Eres mayor de edad");
} else {
  console.log("Eres menor de edad");
}

    Y con else if podemos encadenar varias condiciones:

    let nota = 8;

if (nota >= 9) {
  console.log("Sobresaliente");
} else if (nota >= 7) {
  console.log("Notable");
} else if (nota >= 5) {
  console.log("Aprobado");
} else {
  console.log("Suspenso");
}

    La primera condición que se cumpla es la que se ejecuta. Las siguientes se ignoran, por eso el orden de las condiciones importa.

    Las condiciones usan los operadores de comparación (===, >, <, etc.) y lógicos (&&, ||, !) que ya vimos en el tema de operadores.

    Operador ternario

    Es una forma abreviada de if / else que devuelve un valor. Útil para asignaciones sencillas.

    let edad = 20;
let mensaje = edad >= 18 ? "Mayor de edad" : "Menor de edad";

    La sintaxis es:

    condicion ? valorSiVerdadero : valorSiFalso

    Recuerda (ya lo vimos en el tema de operadores): úsalo solo para condiciones simples. Si la lógica se complica, es más legible un if / else normal.

    switch

    switch permite comparar una variable con varios valores concretos. Es una alternativa a else if cuando comparamos la misma expresión con muchos valores.

    let dia = "lunes";
let tipo;

switch (dia) {
  case "lunes":
  case "martes":
  case "miércoles":
  case "jueves":
  case "viernes":
    tipo = "laborable";
    break;
  case "sábado":
  case "domingo":
    tipo = "fin de semana";
    break;
  default:
    tipo = "no válido";
}

    Puntos a tener en cuenta:

    • Cada case debe terminar con break. Si no lo pones, la ejecución continúa al siguiente case, comportamiento conocido como fall-through.
    • El bloque default se ejecuta cuando ningún case coincide (opcional).
    • La comparación que hace switch es estricta (===).

    Bucles

    Los bucles repiten un bloque de código varias veces.

    for

    Se usa cuando sabemos cuántas veces queremos repetir. Tiene tres partes: inicialización, condición e incremento.

    for (let i = 0; i < 5; i++) {
  console.log(i);
}
// 0 1 2 3 4

    Es muy habitual recorrer un array con for:

    let frutas = ["manzana", "pera", "plátano"];

for (let i = 0; i < frutas.length; i++) {
  console.log(frutas[i]);
}

    for...of

    Una forma más moderna y legible de recorrer los elementos de un array (o cualquier iterable):

    let frutas = ["manzana", "pera", "plátano"];

for (let fruta of frutas) {
  console.log(fruta);
}

    Para recorrer arrays, for...of es casi siempre mejor opción que el for clásico: es más corto y no tienes que gestionar el índice a mano.

    while

    Repite mientras la condición sea verdadera. Se usa cuando no sabemos de antemano cuántas veces se ejecutará.

    let contador = 0;

while (contador < 3) {
  console.log(contador);
  contador++;
}
// 0 1 2

    Cuidado: si la condición nunca se vuelve falsa, tendrás un bucle infinito que bloquea el programa. Asegúrate de que la condición cambie en algún momento del bucle.

    do while

    Igual que while, pero garantiza que el bloque se ejecute al menos una vez, porque la condición se comprueba al final.

    let numero;

do {
  numero = prompt("Introduce un número");
} while (numero === null);

    Aquí el bloque se ejecuta como mínimo una vez, lo que es útil cuando quieres pedir datos hasta que el usuario responda correctamente.

    break y continue

    Dentro de un bucle:

    • break detiene el bucle por completo.
    • continue salta a la siguiente iteración, ignorando el resto del código del bucle en esa vuelta.
    for (let i = 0; i < 10; i++) {
  if (i === 3) continue;   // se salta el 3
  if (i === 7) break;      // para en el 7
  console.log(i);
}
// 0 1 2 4 5 6

    Buenas prácticas

    • Usa === y !== siempre, nunca == o !=.
    • Empieza con las condiciones más restrictivas o específicas en un bloque if / else if.
    • No anides muchos if. Si necesitas más de dos niveles, plantéate separar la lógica en funciones.
    • Para recorrer arrays usa for...of en lugar del for clásico salvo que necesites el índice.
    • Usa switch solo cuando compares una misma variable con muchos valores concretos.
    • Nombra las condiciones con variables descriptivas para que el código se lea solo:
    let tienesPermiso = esAdmin && !estaBloqueado;

if (tienesPermiso) {
  // ...
}
