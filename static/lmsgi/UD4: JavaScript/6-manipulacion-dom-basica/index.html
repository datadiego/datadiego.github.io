    Manipulacion de DOM

    El uso principal de JavaScript es manipular el DOM, esto nos permite crear, modificar y eliminar elementos HTML en una página web, creando una experiencia de usuario dinámica y personalizada.

    Entendiendo el DOM

    El DOM (Document Object Model) es una representación estructurada de un documento HTML, que permite acceder y manipular los elementos de la página web.

    Piensa en este documento HTML:

    <!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>Cafetería La Esquina</title>
</head>
<body>
    <header>
        <h1>Cafetería La Esquina</h1>
        <p>El mejor café del barrio</p>
    </header>
    <nav>
        <a href="#">Inicio</a>
        <a href="#">Carta</a>
        <a href="#">Contacto</a>
    </nav>

    <main>
        <section>
            <h2>Nuestra carta</h2>
            <ul>
                <li>Café con leche</li>
                <li>Chocolate caliente</li>
                <li>Tarta de queso</li>
            </ul>
        </section>
        <section>
            <h2>Horario</h2>
            <p>Lunes a viernes: 08:00 - 20:00</p>
        </section>

    </main>
    <footer>
        <p>© 2026 Cafetería La Esquina</p>
    </footer>
</body>
</html>

    Su DOM sería este:

    .
└── html
    ├── head
    │   ├── meta
    │   └── title
    └── body
        ├── header
        │   ├── h1
        │   └── p
        ├── nav
        │   ├── a
        │   ├── a
        │   └── a
        ├── main
        │   ├── section
        │   │   ├── h2
        │   │   └── ul
        │   │       ├── li
        │   │       ├── li
        │   │       └── li
        │   └── section
        │       ├── h2
        │       └── p
        └── footer
            └── p

    De manera que cada etiqueta HTML es un nodo en el DOM al que javascript puede acceder y manipular.

    Manipulando html con javascript

    Vamos a partir de un html simple:

    <!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>Manipulacion DOM</title>
  </head>
  <body>
    <h1>Un titulo</h1>

    <div id="seccion1">
      <h2>Seccion 1</h2>
      <p>Algo de texto</p>
    </div>

    <div id="seccion2">
      <h2>Seccion 2</h2>
      <p>Otro texto en otra sección</p>
    </div>

  <script src="main.js"> </script>
  </body>
</html>

    Lanza un servidor http y comprueba que ves el contenido del html.

    Vamos a trabajar en nuestro main.js, aunque también puedes hacerlo desde la consola de desarrollo del navegador.

    document.body.textContent = "hola mundo"

    Comprobarás que ha desaparecido todo el contenido del body.

    document es un objeto al que llamarás continuamente para modificar el DOM, tiene muchos métodos, aunque con muy pocos podrás manipular el DOM sin problema:

    Selectores

    document.querySelector()

    Esta función te permite capturar elementos que ya existen en el DOM, usando selectores CSS, y devuelve un elemento html:

    const h1 = document.querySelector('h1');
console.log(h1)
console.log(h1.textContent)

    Si miras la consola de desarrollo, verás que la constante h1 es un objeto, con múltiples propiedades que veremos como modificar más adelante.

    Cuando usamos querySelector con un elemento como h1 que sólo se espera que exista uno en el documento es fácil, pero ¿que elemento devuelve algo como esto?

    const div = document.querySelector("div")

    Esto es muy importante, tenemos dos elementos <div>, pero querySelector solo te devolverá el primero que encuentre.

    Entonces, ¿como seleccionamos el segundo <div>?

    Aqui es donde entra un buen uso de los id en nuestros tags html, o selectores CSS avanzados, para seleccionar el segundo div, podemos utilizar cualquiera de los siguientes:

    //por id
document.querySelector("#seccion2")
// por etiqueta + id (mas especifico)
document.querySelector("div#seccion2")
// segundo div del documento
document.querySelector("div:nth-of-type(2)")
// tercer hijo del body
document.querySelector("body > div:nth-child(3)")

    ¿Cual es la mejor forma? En realidad todas son válidas, y podrás usar selectores similares en otros documentos, aunque los que dependen de la posición son muy frágiles, con cualquier cambio en el documento html pueden dejar de seleccionar el elemento deseado.

    Recuerda, querySelector te devuelve un HTMLElement.

    document.querySelectorAll

    En ocasiones necesitamos capturar múltiples elementos, querySelectorAll también permite seleccionar mediante un selector CSS, pero devuelve todos los elementos en un objeto de tipo NodeList:

    const divs = document.querySelectorAll('div');
console.log(typeof divs)
console.log(divs)

    Lo más natural es tratarlos como un array, puedes convertirlo usando Array.from():

    let divs = document.querySelectorAll('div');
let listaDivs = Array.from(divs)
// o más corto
divs = Array.from(document.querySelectorAll('div'))

    document.getElementById()

    El propio nombre es bastante explicativo, solo funciona con elementos que tengan un id:

    document.querySelector('#seccion1')
document.getElementById('seccion1')

    En el ejemplo anterior, ambas lineas son equivalentes, aunque la segunda suele ser más explícita.

    Este método, al igual que querySelector devuelve un HTMLElement.

    Elementos

    document.createElement()

    En ocasiones en lugar de seleccionar un elemento que ya existe, lo que queremos es crearlo e insertarlo en el documento, podemos hacerlo con document.createElement():

    const p = document.createElement("p")
const otroParrafo = document.createElement("p")
const div = document.createElement("div")
console.log(p, otroParrafo, div)

    Una vez los tenemos creados, podemos modificar sus propiedades, como el contenido de ese elemento, e insertarlos en nuestro documento donde necesitemos.

    Todos los elementos creados con este método son del tipo HTMLElement

    Propiedades de objetos HTMLElement

    Una vez tienes un elemento html en JavaScript, puedes acceder y modificar sus propiedades, por ejemplo:

    document.querySelector('h1').textContent = 'hola mundo'

    HTMLElement.textContent es el contenido que escribirías dentro del propio tag <h1></h1>.

    Cuando manipulas elementos html con javascript simplemente piensa que si puedes escribirlo en html, puedes hacerlo con javascript, cualquier propiedad se puede crear, manipular o eliminar. Por ejemplo:

    const h1 = document.querySelector('h1');
h1.textContent = 'Vamos a añadir varias propiedades'
h1.classList = "rojo centrado"
h1.id = "mititulo"
h1.hidden = true

    Si miras el html generado:

    <h1 class="rojo centrado" id="mititulo" hidden="">hola mundo</h1>

    Da igual que elemento html estés manipulando, podrás modificar sus propiedades igual que harías con html plano:

    const img = document.createElement('img')
img.src = "https://url.com/imagen.png"

    HTMLElement.appendChild()

    Ya te habrás dado cuenta que crear un elemento html en js no lo inserta en tu documento.

    Podemos insertar un elemento HTML que tengamos seleccionado en js en otro elemento HTML usando elemento1.appendChild(elemento2), por ejemplo:

    const primerDiv = document.querySelector("#seccion1")
const segundoDiv = document.querySelector("#seccion2")
const primerParrafo = document.createElement("p")
const segundoParrafo = document.createElement("p")

primerParrafo.textContent = "Este parrafo irá a la seccion 1"
segundoParrafo.textContent = "Este parrafo irá a la seccion 2"

primerDiv.appendChild(primerParrafo)
segundoDiv.appendChild(segundoParrafo)

    Esto es fundamental en muchos elementos, como listas:

    const frutas = ["manzana", "melocoton", "platano"]
const lista = document.createElement("ul")

for (let i=0; i < frutas.length; i++){
  const li = document.createElement("li")
  li.textContent = frutas[i]
  lista.appendChild(li)
}
document.body.appendChild(lista)
