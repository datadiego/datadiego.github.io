    Funciones

    Aunque Javascript puede crear clases, principalmente utiliza un paradigma funcional.

    En lugar de crear clases con métodos, es común crear funciones y encadenarlas para conseguir nuestro propósito, por ello, el lenguaje es muy versátil acerca de cómo crearlas y que podemos hacer con ellas.

    Definir funciones

    La sintaxis para definir una función es la siguiente:

    function miFuncion(a,b){
  return a+b
};

    Podemos invocarla asi:

    miFuncion(1,2);

    Argumentos

    Podemos definir valores por defecto:

    function saludo(nombre="usuario"){
  return `hola ${nombre}`
}

console.log(saludo()) //hola usuario
console.log(saludo("Javier")) //hola Javier

    Funciones anónimas

    Podemos crear funciones anónimas, estas funciones no tienen nombre definido, y las identificarás por el simbolo =>, también son llamadas función flecha debido a esto:

    (a, b) => { return a + b }

    Se pueden acortar aún más, si nuestra función solo tiene una linea, podemos quitar tanto los {}, y el return es implícito, una función anónima siempre devuelve el resultado de lo que forma su cuerpo:

    (a, b) => a + b

    Si una función no tiene nombre, ¿como la invocamos? Tenemos varias formas:

    IIFE

    Podemos hacer lo siguiente:

    ((a,b) => a + b)(1,2)

    Esto es un IIFE (Inmediately Invoked Function Expression), es una función que se define y ejecuta inmediatamente, sin necesidad de llamarla luego.

    Los IIFE se usan cuando no queremos crear un scope privado, y que el usuario no pueda acceder a ciertas funciones o variables del juego.

    Por ejemplo, si estás creando un juego incremental/clicker, dejar tus variables y funciones asi:

    let points = 0;

function addPoints(value){
  points += value
}

    Hace que el jugador pueda simplemente abrir la terminal y modificar el valor de los puntos o ejecutar la función a su antojo.

    Envolviendolas en un IIFE no tendriamos este problema.

    Almacenarla en una variable

    Podemos almacenar la función en una constante, y llamarla luego:

    const suma = (a, b) => a + b

    Se usa mucho para acortar funciones y dejarlas en una sola linea, compara esto:

    function dumbify(string){
  const arr = string.split("")
  const arr2 = []
  for(i = 0; i < arr.length; i++){
    if(i % 2 == 0){
      arr2.push(arr[i].toLowerCase())
    } else{
      arr2.push(arr[i].toUpperCase())
    }
  }
  const result = arr2.join("")
  return result
}

    A esto:

    const dumbify = (string) => string.split("").map((c,i) => i % 2 == 0 ? c.toUpperCase() : c.toLowerCase()).join("")

    La primera es más explícita, la segunda cuesta de entender a gente nueva, pero ahorra muchísimo espacio poder crear lógicas complejas en una linea.

    Uso en funciones de alto nivel

    Los veremos en una sección dedicada exclusivamente a este tipo de funciones, aunque en el ejemplo anterior:

    const dumbify = (string) => string.split("").map((c,i) => i % 2 == 0 ? c.toUpperCase() : c.toLowerCase()).join("")

    Esta parte:

    map((c,i) => i % 2 == 0 ? c.toUpperCase() : c.toLowerCase())

    Ya hace uso de una función anónima en una función de alto nivel, Array.map().

    Esta función está almacenada en una constante, podemos invocarla con miFuncion(), pero nos permite hacer más cosas.

    Por ejemplo, imagina que tenemos estas dos funciones:

    function repetirSaludo(n, nombre){
  for (let index = 0; index < n; index++) {
    console.log(`Hola ${nombre}`)
  }
}

function repetirDoble(n, valorInicial){
  for (let index = 0; index < n; index++) {
    valorInicial *= 2
  }
  return valorInicial
}

repetirSaludo(5, "pepe")
let valor = 1;
valor = repetirDoble(3, valor)
console.log(valor)

    ¿No hacen prácticamente lo mismo? Ambas repiten una acción n veces. Una repite un console.log() y otra repite una operación matemática.

    Podemos hacer una función más genérica que sirva para ambas:

    function repetir(n, fun){
  let resultado
  for (let index = 0; index < n; index++) {
    resultado = fun(index)
  }
  return resultado
}

    Ahora la función repetir espera dos argumentos, n para indicar y fun, una función en la que declararemos que hacer repetidamente:

    repetir(5, () => console.log('Hola pepe'))
let valor = 1
let resultado = repetir(3, () => valor *= 2)
console.log(resultado)

    Ahora tenemos una función genérica, que podemos reutilizar para repetir con diferentes propósitos. Además, a fun(index) le está llegando el valor de index en cada iteración, podemos accederlo si lo necesitamos:

    repetir(5, (iteracion) => console.log(iteracion))

    Javascript tiene muchas funciones y métodos que esperan que uses funciones anónimas, por ejemplo:

    const frutas = ['manzana', 'peras', 'platano']

frutas.forEach((fruta) => {
  console.log(fruta)
})

    Cualquier lista de javascript tiene un método forEach que te permite recorrer la lista, obteniendo cada uno de los elementos y hacer algo con ese elemento, el método te da libertad de hacer lo que quieras con el:

    const frutas = ['manzana', 'peras', 'platano']

frutas.forEach((fruta) => {
  console.log(fruta.toUpperCase())
})

    Acortando funciones

    Las funciones anónimas permiten acortar bastante el declarar una función, usando function, si nuestra función puede resumirse en una linea, podemos hacer:

    function suma(a, b){ return a+b }

    En una función anónima, si nuestra función solo tiene una linea, podemos hacer:

    const suma = (a,b) => return a+b

    Y de hecho, no tenemos ni que añadir return, es implícito:

    const suma = (a,b) => a+b
    ```
