    MySQL: Instalación y configuración

    Vamos a instalar y configurar un servidor básico de MySQL en Fedora.

    Instalación y arranque

    Para instalar el servidor:

    sudo dnf install -y mysql-server

    Ahora debemos arrancar el daemon que correrá en segundo plano:

    sudo systemctl start mysqld.service

    Comprueba que está funcionando:

    ❯ sudo systemctl status mysqld.service

    Si quieres que el servidor arranque junto a tu sistema haz sudo systemctl enable mysqld.service.

    Configuración básica

    MySQL se configura en un archivo de texto localizado en /etc/my.cnf, solo se puede acceder por root para editarlo.

    Por ahora, solo necesitarás esto:

    [client-server]
!includedir /etc/my.cnf.d

[mysqld]
bind-address = 0.0.0.0
port = 3306

    Con bind-address puedes cambiar en que dirección IP local sale tu servidor:

    • 127.0.0.1: Solo puede acceder quien esté en el mismo sistema que myslq está instalado.
    • 0.0.0.0: Cualquiera puede acceder por el puerto en el que está configurado.

    Con port establecemos qué puerto de conexión usamos. El puerto por defecto es 3306.

    En producción es aconsejable cambiar el puerto por defecto. Aunque esto por si solo no protegerá el descubrimiento del mismo por un atacante.

    Para recargar la configuración, reinicia el servidor:

    sudo systemctl restart mysqld.service

    Creando una base de datos

    Igual que podemos crear múltiples archivos .db con sqlite3, en mysql podemos crear múltiples bases de datos diferentes, con múltiples tablas en su interior.

    Vamos a acceder con el usuario de administrador a nuestro servidor con sudo mysql:

    ❯ sudo mysql
[sudo] contraseña para datadiego:
Welcome to the MySQL monitor.  Commands end with ; or \g.
Your MySQL connection id is 9
Server version: 8.4.10 Source distribution

Type 'help;' or '\h' for help. Type '\c' to clear the current input statement.

mysql>

    Para crear una base de datos lanza CREATE DATABASE nombre_db;:

    mysql> CREATE DATABASE prueba;
Query OK, 1 row affected (0,01 sec)

    Ahora podemos comprobar las bases de datos existentes con SHOW DATABASES;

    mysql> SHOW DATABASES;
+--------------------+
| Database           |
+--------------------+
| information_schema |
| mysql              |
| performance_schema |
| prueba             |
| sys                |
+--------------------+
5 rows in set (0,00 sec)

    Para entrar a una base de datos hacemos USE nombre_db:

    mysql> USE prueba;
Database changed

    Ahora podemos crear tablas, insertar datos, leerlos y modificarlos:

    mysql> CREATE TABLE test(
    -> nombre VARCHAR(100),
    -> edad INT
    -> );
Query OK, 0 rows affected (0,02 sec)

mysql> INSERT INTO test VALUES ('pepe', 23);
Query OK, 1 row affected (0,02 sec)

mysql> SELECT * FROM test;
+--------+------+
| nombre | edad |
+--------+------+
| pepe   |   23 |
+--------+------+
1 row in set (0,00 sec)

mysql> UPDATE test SET edad = 50 WHERE nombre = 'pepe';
Query OK, 1 row affected (0,01 sec)
Rows matched: 1  Changed: 1  Warnings: 0

mysql> SELECT * FROM test;
+--------+------+
| nombre | edad |
+--------+------+
| pepe   |   50 |
+--------+------+
1 row in set (0,00 sec)

    Puedes ejecutar archivos .sql desde este REPL con source:

    mysql> source /tmp/test/schema.sql
Query OK, 0 rows affected (0,02 sec)

mysql> show tables;
+------------------+
| Tables_in_prueba |
+------------------+
| ejemplo          |
| test             |
+------------------+
2 rows in set (0,01 sec)
