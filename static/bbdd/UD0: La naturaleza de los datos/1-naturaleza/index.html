    Naturaleza y clasificación de los datos

    Ya sabemos que los datos son representaciones de información que podemos recopilar, almacenar y analizar para tomar decisiones.

    Según su naturaleza, pueden clasificarse de diferentes maneras.

    • Cuantitativos y cualitativos
    • Numéricos, textuales, temporales, booleanos y binarios
    • Discretos, continuos
    • Categóricos, nominales y ordinales
    • Datos estructurados, semiestructurados y no estructurados

    Cuantitativos y cualitativos

    Representan si son datos numéricos o cualidades y características con las que no podemos realizar operaciones matemáticas.

    Cuantitativos

    Son datos que representan cantidades numéricas. Permiten realizar operaciones matemáticas como sumar, restar, calcular promedios, porcentajes, etc.

    El producto está al 20% de descuento

    Tenemos 135 usuarios en nuestra aplicación

    La temperatura es de 23.5ºC

    Cualitativos

    No permiten operaciones. Describen cualidades o características de algo.

    Color de los ojos de alguien

    Estado civil de una persona

    El tipo de producto al que nos referimos en una tienda

    Numéricos, textuales, temporales, booleanos y binarios

    Es el tipo de formato del dato.

    Todos los ejemplos están hechos en Python.

    Numéricos

    Representan números, pueden realizarse operaciones matemáticas con ellos.

    >>> a=23
>>> b=1
>>> a+b
24

    Textuales

    Representan un caracter de texto, o una cadena de varios caracteres.

    >>> a="23"
>>> b="1"
>>> a+b
'231'
>>> a="hola"
>>> b="mundo"
>>> a + " " + b
'hola mundo'

    Temporales

    Representan una fecha, hora, o momento concreto en el tiempo:

    >>> from datetime import datetime
>>> ahora = datetime.now()
>>> ahora
datetime.datetime(2026, 9, 2, 12, 23, 13, 602987)
>>> ahora.isoformat()
'2026-09-02T12:23:13.602987'
>>> ahora.timestamp()
1788344593.602987
>>>

    isoformat es una forma de representar una fecha en texto, siguiendo un estandar publicado por el organismo ISO.

    timestamp sigue el formato Unix Epoch, en el que se establece como punto de referencia el 1 de Enero de 1970 a las 00:00:00 UTC, a partir de ahi, se cuenta cuanto tiempo ha pasado y se devuelve como un número.

    1970-01-01 00:00:00 UTC → 0
1970-01-01 00:00:01 UTC → 1
1970-01-01 00:01:00 UTC → 60
1970-01-02 00:00:00 UTC → 86400

    Booleanos

    Los valores booleanos son datos que solo pueden ser Verdadero o Falso, por ejemplo, un interruptor, la asistencia a clase o si estás vivo.

    >>> def is_dead(estado):
...     if(estado == True):
...         print("El jugador murió")
...     else:
...         print("El jugador sigue vivo")
...
>>> is_dead(True)
El jugador murió
>>> is_dead(False)
El jugador sigue vivo
>>> is_dead("False")
El jugador sigue vivo
>>> is_dead(0)
El jugador sigue vivo
>>> is_dead(1)
El jugador murió
>>> is_dead(25)
El jugador sigue vivo
>>> is_dead("si")
El jugador sigue vivo

    Binarios

    Valores que solo pueden tener dos posibles valores, 0 y 1.

    Está muy relacionados con True y False, pero no son lo mismo.

    Archivos binarios

    Estos datos son mas fáciles de interpretar si sabes como funciona el modelo de color hexadecimal RGB:

    En el modelo RGB dividimos cualquier color en una combinacion de rojo, verde y azul.

    Cada color puede tener un valor entre 0 255

    En hexadecimal, el valor 0 se traduce como 0, y el valor 255 como FF

    • El color blanco en formato hexadecimal es #FFFFFF.
    • El color negro en formato hexadecimal es #000000.
    • El color rojo en formato hexadecimal es #FF0000.
    • El color verde en formato hexadecimal es #00FF00.

    Discretos y continuos

    Valores que se pueden contar o que pueden tomar valores en un rango.

    Discretos

    Nos permiten contarlos, y toman valores separados, no tendría sentido decir:

    Tengo 2,31 hijos

    Continuos

    Se pueden medir y tomar un valor en un intervalo.

    1.78 metros

    1.62 segundos

    20.5 kilos

    Categóricos

    Hay datos cualitativos que se pueden agrupar, por ejemplo:

    Blanco
Negro
Rojo
Verde
Azul

    Todos estos datos cualitativos se pueden agrupar bajo color.

    Distinguimos dos tipos de datos categóricos:

    Nominales

    No tienen un orden natural, pueden ser colores, pais, tipo de vehiculo, etc...

    Nos da igual decir:

    Blanco -> Negro -> Rojo -> Verde -> Azul
Azul -> Verde -> Rojo -> Negro -> Blanco

    No existe un orden determinado en una lista de colores.

    Ordinales

    Tienen un orden, aunque no se pueda medir la distancia entre ellas:

    Bajo -> Medio -> Alto
Pequeño -> Mediano -> Grande
Feliz -> Neutral -> Triste
S -> M -> L -> XL

    Estructurados, semiestructurados y no estructurados

    Aqui no nos fijamos en si es cualitativo, cuantitavio, o el formato que presentan. Solo en como los ordenamos y organizamos.

    Estructurados

    Estructura clara y bien definida, generalmente mediante filas y columnas:

    nombre edad email
    Diego 35 diego@gmail.com
    Pepe 22 pepe@gmail.com
    Maria 26 maria@gmail.com
    Elvira 29 elvira@gmail.com

    Aqui tenemos 3 columnas (nombre, edad y email) y 4 filas con los datos de diferentes usuarios. Cada columna tiene un dato y significado definido.

    Semiestructurados

    No tienen una estructura rígida, pero contienen etiquetas y campos que permiten identificar y organizar información:

    [
  {
    "nombre": "Diego",
    "edad": 35,
    "email": "diego@gmail.com"
    "isAdmin": true
  },
  {
    "edad": 22,
    "nombre": "Pepe",
    "email": "pepe@gmail.com"
  },
  {
    "edad": 26,
    "email": "maria@gmail.com"
    "nombre": "Maria",
    "bio": "Hola! Me llamo Maria"
  },
  {
    "edad": 29,
    "email": "elvira@gmail.com"
    "nombre": "Elvira",
  }
]

    No estructurados

    No siguen un esquema fácil de seguir, los datos se ordenan de manera compleja y requieren software especializado para tratarlo.

    Vamos a seguir el ejemplo que vimos antes de las imágenes, estos datos suelen llevar una estructura más o menos compleja, no presentan los datos de una manera totalmente estructurada como esperamos.

    Si conviertes la imágen creada previamente a formato bmp con convert imagen.png imagen.bmp, buscas el valor FFFFFF correspondiente al blanco y lo cambias por FF0000 el primer pixel cambiará a rojo. Pero si intentas lo mismo con el png este se corrompe por completo, y la imagen no se podrá interpretar correctamente.
