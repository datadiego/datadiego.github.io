    Introducción

    Las bases de datos embebidas funcionan en el propio dispositivo que las consume. Generalmente los datos se almacenan en memoria o en un archivo si queremos conservar los datos.

    La más usada es SQLite, es la mejor forma de comenzar a aprender el lenguaje SQL que luego heredaremos en otros motores como MySQL, MariaDB o Postgre.

    Instalación

    En muchas distribuciones Linux, ya tienes sqlite instalado.

    Si no lo tienes instalado, se suele distribuir bajo el nombre sqlite o sqlite3.

    Primeros pasos

    Para usar sqlite no necesitas configurar nada, solo necesitas una base de datos ya creada, o crearla tu usando sentencias SQL.

    Las sentencias SQL se pueden ejecutar directamente como comandos, o almacenarlos en archivos .sql si son largas o queremos conservarlas.

    Creando una base de datos

    Para crear una base de datos necesitarás usar una sentencia CREATE en SQL que defina la tabla que quieres crear:

    CREATE TABLE alumnos(
  nombre TEXT,
  edad INTEGER
);

    Generalmente, los archivos que definen tablas de una base de datos se llaman schemas. Es buena idea almacenar la definicion de tus tablas como schema.sql para identificarlas rápidamente:

    /tmp/testsqlite
❯ cat schema.sql
CREATE TABLE alumnos(
  nombre TEXT,
  edad INTEGER
);


/tmp/testsqlite
❯ cat select-alumnos.sql
SELECT * FROM alumnos;

    Ejecutando archivos .sql

    Para ejecutar un archivo que contenga sentencias sql con sqlite ejecuta:

    sqlite3 archivo.db < archivo.sql

    Ejecutando sentencias

    No necesitas crear archivos .sql para todo, por ejemplo, podemos insertar una fila en la tabla creada anteriormente haciendo:

    sqlite3 archivo.db "INSERT INTO alumnos VALUES ('pepe', 22)"

    Luego, podemos leer la tabla:

    sqlite3 archivo.db "SELECT nombre,edad FROM alumnos"

    Ejemplo completo

    Aqui puedes ver como se puede crear una base de datos almacenada en un archivo test.db, como insertar datos en la misma, y como consultarla:

    /tmp/testsqlite
❯ ls
.rw-r--r--@   56 datadiego  3 sep 13:01 schema.sql
.rw-r--r--@   23 datadiego  3 sep 13:02 select-alumnos.sql

/tmp/testsqlite
❯ cat schema.sql
CREATE TABLE alumnos(
  nombre TEXT,
  edad INTEGER
);

/tmp/testsqlite
❯ sqlite3 test.db < schema.sql

/tmp/testsqlite
❯ ls
.rw-r--r--@   56 datadiego  3 sep 13:01 schema.sql
.rw-r--r--@   23 datadiego  3 sep 13:02 select-alumnos.sql
.rw-r--r--@ 8,2k datadiego  3 sep 13:06 test.db

/tmp/testsqlite
❯ sqlite3 test.db "INSERT INTO alumnos VALUES ('pepe', 22)"

/tmp/testsqlite
❯ sqlite3 test.db "INSERT INTO alumnos VALUES ('maria', 20)"

/tmp/testsqlite
❯ sqlite3 test.db "INSERT INTO alumnos VALUES ('javier', 26)"

/tmp/testsqlite
❯ cat select-alumnos.sql
SELECT * FROM alumnos;

/tmp/testsqlite
❯ sqlite3 test.db < select-alumnos.sql
pepe|22
maria|20
javier|26

/tmp/testsqlite
❯ sqlite3 test.db "SELECT nombre FROM alumnos WHERE edad > 25"
javier
