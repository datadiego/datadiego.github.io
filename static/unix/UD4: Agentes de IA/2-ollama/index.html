    Ollama

    ollama es una herramienta para ejecutar modelos de inteligencia artificial localmente.

    Puedes desarrollar tus propios modelos y usarlos con ollama, o descargar modelos ya entrenados,

    Instalación

    Suele estar disponible en tu gestor de paquetes, si no lo encuentra, usa el script oficial desde la página de ollama.

    Uso de ollama

    Activando el servicio

    Para funcionar, ollama necesita un backend funcionando en segundo plano, actívalo:

    sudo systemctl start ollama

    Descarga un modelo

    Utiliza ollama pull <modelo> para descargar un modelo, vamos a probar con uno ligero:

    ollama pull qwen2.5:0.5b-instruct-q5_K_M

    Comprobar modelos disponibles

    Utiliza ollama list para ver que modelos tienes disponibles una vez termine de descargarlo:

    ❯ ollama list
NAME                            ID              SIZE      MODIFIED
qwen2.5:0.5b-instruct-q5_K_M    0762ec590a8c    420 MB    25 hours ago

    Ejecuta el modelo

    Puedes ejecutarlo directamente desde el CLI con ollama run <modelo>:

    ollama run qwen2.5:0.5b-instruct-q5_K_M

    Ahora puedes hablar con el modelo y comprobar que todo funciona bien.

    Uso de CPU

    Dependiendo de que GPU uses, tendrás que decirle a ollama que haga uso de la misma.

    Mientras ejecutas un modelo, en otra terminal, lanza ollama ps para ver que modelos están corriendo y que recursos están utilizando:

    NAME                            ID              SIZE      PROCESSOR    CONTEXT    UNTIL              
qwen2.5:0.5b-instruct-q5_K_M    0762ec590a8c    464 MB    100% CPU     4096       4 minutes from now

    Ahora mismo está usando la CPU, no la GPU.

    Configurar la GPU depende bastante de tu sistema, pero vamos a ver una forma muy sencilla de hacerlo en la siguiente sección.

    Si estás ejecutando Linux desde una máquina virtual tu GPU no será visible y su configuración es más complicada.
