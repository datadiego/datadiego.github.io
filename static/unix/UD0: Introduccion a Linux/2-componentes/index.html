    Componentes

    Para entender que son las distros de Linux, debemos conocer algunos componentes que son comunes a todas ellas.

    ¿Un ke? Un kernel

    De forma general, escucharás hablar de Linux como un sistema operativo, pero es un error común, Linux en realidad es un kernel.

    El kernel es el núcleo del sistema: se encarga de gestionar el hardware, la memoria, los procesos, la red y otros recursos del sistema.

    Es el encargado de hablar directamente con los componentes físicos de tu equipo.

    Pero un kernel por sí solo no nos da un sistema que podamos utilizar cómodamente. Una distribución reúne el kernel con muchas otras piezas de software para construir un sistema completo.

    Una distro reúne el kernel junto a muchas otras piezas de software para crear un sistema operativo completo.

    Componentes

    De forma simplificada, puedes imaginar los componentes de una distro asi:

    flowchart LR
    Distro["Distro"]

    Distro --> Kernel["Kernel Linux"]
    Distro --> User["User space"]
    Distro --incluye --> Apps["Aplicaciones"]

    Kernel -- gestiona --> Hardware["Hardware"]

    User -- inicia el sistema --> Init["Init"]
    User -- interpreta comandos --> Shell["Shell"]
    User -- funcionan en segundo plano --> Services["Servicios / daemons"]
    User -- puede incluir --> Graphics["Sistema gráfico"]

    Graphics -- entorno completo --> DE["Desktop Environment"]
    Graphics --gestiona ventanas --> WM["Window Manager / Compositor"]

    Distro --> Packages["Gestor de paquetes + repositorios"]
    Packages -- Gestiona e instala --> Apps

    Kernel

    El núcleo del sistema. Gestiona los recursos del ordenador y proporciona una interfaz para que el resto del software pueda utilizarlos.

    Bootloader

    Es el encargado de iniciar el sistema y cargar el kernel.

    Los más conocidos son GRUB y systemd-boot.

    Init / sistema de inicio

    Una vez arrancado el kernel, se necesita un proceso inicial que ponga en marcha el resto del sistema.

    El más utilizado actualmente es systemd, aunque existen alternativas como OpenRC o runit.

    Además de iniciar servicios, estos sistemas suelen encargarse de otras tareas relacionadas con la gestión del sistema.

    User space

    Todo el software que se ejecuta fuera del kernel.

    Aquí encontramos prácticamente todo lo que utilizamos directamente: comandos, librerías, servicios, shells, servidores gráficos, aplicaciones, etc.

    Una distro necesita proporcionar un user space completo alrededor del kernel para convertirse en un sistema utilizable.

    Shell y herramientas básicas

    La shell permite interactuar con el sistema mediante comandos.

    Bash, Zsh y Fish son algunos ejemplos.

    Junto a ellas encontramos cientos de herramientas básicas para trabajar con archivos, procesos, usuarios, redes, dispositivos, etc.

    Servicios y daemons

    Son programas que funcionan en segundo plano y proporcionan diferentes funcionalidades: red, impresión, audio, acceso remoto, sincronización, servidores, etc.

    El sistema de inicio suele encargarse de gestionarlos.

    Sistema gráfico

    Si queremos utilizar un escritorio gráfico necesitamos una serie de componentes que se encarguen de mostrar ventanas, gestionar la entrada del usuario y renderizar la interfaz.

    Hoy encontramos principalmente X11 y Wayland.

    Sobre ellos podemos construir un Window Manager o un Desktop Environment.

    Desktop Environment

    Un Desktop Environment reúne muchos componentes para proporcionar una experiencia de escritorio completa.

    Por ejemplo, GNOME y KDE Plasma incluyen paneles, configuraciones, aplicaciones, gestores de archivos y otros componentes integrados.

    También podemos prescindir de un DE completo y utilizar solamente un Window Manager o compositor, como i3, Sway o Hyprland.

    Gestor de paquetes

    Una distro también necesita una forma de instalar y mantener su software.

    El package manager se encarga de instalar, actualizar y eliminar paquetes, además de resolver sus dependencias.

    Por ejemplo:

    Debian → apt
Arch → pacman
Fedora → dnf

    Y muchas cosas más

    Una distribución también incluye drivers, librerías, firmware, configuraciones por defecto, documentación, herramientas de administración, repositorios de software, etc.

    No existe una lista universal de componentes que todas las distribuciones deban tener. Cada proyecto decide qué software incluir y cómo configurarlo.
