    Servicios

    Los servicios también son programas que están siendo ejecutados, pero en segundo plano, permiten desde que puedas mandar a imprimir un documento, a compartir directorios en red o montar servidores.

    Para interactuar con los servicios usaremos systemctl

    Estado de servicios

    Para ver el estado de un servicio, haremos systemctl status <servicio>, por ejemplo, cups es el servicio de impresión de documentos:

    ❯ sudo systemctl status cups.service

    Podemos ver que en mi caso su estado es Active, así que está funcionando, mi sistema podrá enviar a una impresora documentos.

    start/stop

    Podemos iniciar y parar servicios con:

    sudo systemctl start <servicio>
sudo systemctl stop <servicio>

    enable/disable

    En el caso anterior, cups está disabled, esto significa que cuando mi sistema hace init al arrancar, no iniciará este servicio.

    Que no lo inicie init no significa que tengamos que iniciarlo siempre manualmente, cups se puede activar automáticamente cuando alguna aplicación lo necesita.

    Instalando y probando un servicio

    Vamos a instalar ollama, un servicio que nos permite ejecutar modelos de inteligencia artificial en nuestro sistema:

    sudo dnf install ollama

    Para instalar modelos, usamos ollama pull <nombre del modelo>, pero si intentamos hacerlo:

    ~
❯ ollama pull qwen2.5:0.5b-instruct-q5_K_M
