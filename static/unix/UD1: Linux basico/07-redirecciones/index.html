    Redirecciones y descriptores

    Las redirecciones de Linux nos permiten manipular los descriptores de Linux.

    Descriptores

    Por defecto, un proceso en Linux puede tener acceso a distintos recursos, como la entrada y salida de la terminal, archivos, sockets, dispositivos, etc.

    Para que el proceso pueda acceder a estos recursos, el kernel utiliza descriptores de archivo, que son números enteros que identifican cada recurso abierto para ese proceso.

    Los tres primeros descriptores tienen un significado estándar:

    0 -> stdin   → entrada estándar
1 -> stdout  → salida estándar
2 -> stderr  → error estándar

    A partir del 3, los siguientes descriptores se asignan a otros recursos que el proceso abra o reciba:

    3 -> archivo abierto
4 -> socket
5 -> pipe
6 -> movimiento del raton
etc.

    Del 2 en adelante, se asignan a conveniencia del kernel, no sabemos cual es el número asignado a cada recurso

    Los que más nos interesan son los tres primeros:

    flowchart TD
    P[Proceso] --> FD[Descriptores]

    FD --> A["0 - stdin<br/>Entrada"]
    FD --> B["1 - stdout<br/>Salida"]
    FD --> C["2 - stderr<br/>Errores"]

    A --> T[Terminal]
    B --> T
    C --> T

    Redirecciones

    Las redirecciones nos permiten redirigir donde van estos descriptores.

    Cuando hacemos:

    ❯ echo "hola mundo"
hola mundo

    La salida 1 (standard output) devuelve el mensaje a la terminal.

    Si intentamos leer un archivo que no existe:

    ❯ cat estonoexiste.txt
cat: estonoexiste.txt: No existe el fichero o el directorio

    La salida 2 (standard error) devuelve el error a la terminal.

    Podemos redirigir un echo a un archivo:

    test on  master [?]
❯ echo "hola mundo" 1> hello.txt

test on  master [?]
❯ cat hello.txt
hola mundo

    Podemos simplemente hacer:

    test on  master [?]
❯ echo "hola mundo" 1> hello.txt

    La redirección por defecto de > es 1.

    Si queremos redirigir un error, debemos hacer:

    test on  master [?]
❯ cat estonoexiste.txt 2> whooops.txt

test on  master [?]
❯ cat whooops.txt
cat: estonoexiste.txt: No existe el fichero o el directorio
