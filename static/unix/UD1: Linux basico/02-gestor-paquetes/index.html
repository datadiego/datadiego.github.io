    Gestión de paquetes

    Vamos a aprender a actualizar, instalar y desinstalar software en nuestro sistema, y en el proceso, varios comandos y conceptos importantes.

    Instalación de software

    Windows y Mac tienen una única forma de instalar software.

    Generalmente el proceso es:

    1. Abre el navegador
    2. Ve a la página de la aplicación
    3. Busca la sección de descargas
    4. Descarga un ejecutable
    5. Ejecuta el archivo que acabas de descargar
    6. Sigue el wizard de instalación
    7. No pulsar Siguiente a lo loco para evitar que instale publicidad o aplicaciones secundarias que no quieres.
    8. Abre tu aplicación

    En Linux, tenemos múltiples formas de instalar software, pero la más común es usando tu gestor de paquetes, el proceso es:

    1. Abre la terminal
    2. Escribe un comando
    3. Abre tu aplicación

    Paquetes

    Un paquete es un archivo que contiene todo lo necesario para poder instalar un programa en tu sistema.

    Incluye, entre otras cosas:

    • Los archivos que ejecutan tu programa
    • Archivos de texto con configuración que puedes editar
    • Una lista de dependencias
    • Metadatos, el nombre, version y descripción del programa
    • Manual de la herramienta
    • Scripts que se ejecutan durante la instalación y desinstalación

    Dependiendo de tu distribución tendrán una extensión diferente, en debian y derivados, son .deb, en fedora son .rpm

    Solo el administrador puede instalar software

    Linux es un sistema multiusuario, puedes crear diferentes usuarios para tu sistema, cada uno con su home y software aislado de los demás.

    Por defecto, tendrás tu propio usuario, es con el que hasta ahora has interactuado con el sistema, y un usuario de administración, llamado root o superusuario.

    Puedes cambiar de comando con el comando su (switch user), en Fedora, normalmente se bloquea el acceso directo a root con este comando. Pero tenemos otras formas de acceder como veremos más adelante.

    sudo

    sudo (switch user do) nos da acceso para ejecutar un comando como otro usuario generalmente como root.

    En fedora, podemos hacer sudo -i para acceder a una terminal como root:

    ~
❯ echo "soy $USER"
soy datadiego

~
❯ sudo -i
[sudo] contraseña para datadiego:
root@fedora:~# echo "soy $USER"
soy root

    Aun asi, en fedora nos limitan el acceso por un buen motivo.

    Es peligroso usar root como usuario normal, es un usuario sin limites que puede destruir el sistema si quiere.

    Gestor de paquetes

    Para poder instalar, desinstalar o actualizar paquetes, necesitarás usar sudo junto al gestor de paquetes de tu distro.

    Cada distro usa un gestor diferente:

    • Debian y derivados usan apt
    • Arch usa pacman
    • Fedora usa dnf

    Cada uno tiene comandos diferentes, pero al final son bastante similares:

    sudo apt install paquete
sudo pacman -S paquete
sudo dnf install paquete

    Nos centraremos en Fedora para el curso, pero pasar a otra distro es fácil una vez te acostumbras a usar el gestor de paquetes de una.

    Actualización del sistema

    Antes de instalar paquetes, es buena idea actualizar nuestro sistema, para esto también usaremos nuestro gestor de paquetes, con el comando dnf upgrade:

    ❯ dnf upgrade
La operación solicitada requiere privilegios de superusuario. Por favor inicie sesión con un usuario con permisos elevados, o utilice las opciones "--assumeno" o "--downloadonly" para ejecutar el comando sin modificar el estado del sistema.

    Nos pide que seamos superusuario, asi que usamos sudo antes del comando para ejecutarlo como root:

    sudo dnf upgrade

    Si en algún momento sabes que ha salido una actualización para algún paquete o fedora, y al lanzarlo no actualiza, fuerza el refresco de la caché con sudo dnf upgrade --refresh

    Instalar paquetes

    Vamos a instalar un comando muy simple, figlet, que nos deja crear ascii art para nuestros textos en terminal, como este:

                                     /$$
                                | $$
  /$$$$$$   /$$$$$$   /$$$$$$  /$$$$$$
 /$$__  $$ /$$__  $$ /$$__  $$|_  $$_/
| $$  \__/| $$  \ $$| $$  \ $$  | $$
| $$      | $$  | $$| $$  | $$  | $$ /$$
| $$      |  $$$$$$/|  $$$$$$/  |  $$$$/
|__/       \______/  \______/    \___/

    Puedes lanzar el comando sudo dnf install <paquete> para instalar cualquier programa. Aunque al intentar lanzarlo también te sugiere que puedes instalarlo:

    ~
❯ figlet "hola linux"
bash: figlet: instrucción no encontrada...
¿Quiere instalar el paquete «figlet» que proporciona la orden «figlet»? [N/y]

    Fedora detecta que no tienes figlet instalado, pero que está disponible para descargar.

    Nos da dos opciones [N/y], la que esta en mayuscula es la que se lanza por defecto si pulsas enter. Escribe y y pulsa enter para instalarlo. Te pedirá confirmación mostrandote información del paquete que descargará:

    Los paquetes siguientes deben instalarse:
 figlet_2.2.5-39.fc44.x86_64  A program for making large letters out of ordinary text
¿Quiere continuar con las modificaciones? [N/y]

    Una vez termine de descargar e instalar figlet, lanzará el comando que mandaste y mostrará el resultado:

     * Esperando en cola...
 * Esperando autenticación...
 * Esperando en cola...
 * Descargando paquetes...
 * Ejecutando...
 * Instalando paquetes...
 _           _         _ _
| |__   ___ | | __ _  | (_)_ __  _   ___  __
| '_ \ / _ \| |/ _` | | | | '_ \| | | \ \/ /
| | | | (_) | | (_| | | | | | | | |_| |>  <
|_| |_|\___/|_|\__,_| |_|_|_| |_|\__,_/_/\_\

    Ahora puedes usarlo en cualquier momento como un comando normal:

    ❯ figlet -f slant fedora
    ____         __
   / __/__  ____/ /___  _________ _
  / /_/ _ \/ __  / __ \/ ___/ __ `/
 / __/  __/ /_/ / /_/ / /  / /_/ /
/_/  \___/\__,_/\____/_/   \__,_/

    Lo mas normal es hacer sudo dnf install figlet si sabes que no tienes instalado el paquete.

    Como ves, podemos usar varias fuentes, pero... ¿como sabemos cuales podemos usar?

    Con el comando whereis podemos saber en que directorios están los archivos relativos a un comando:

    ❯ whereis figlet
figlet: /usr/bin/figlet /usr/share/figlet /usr/share/man/man6/figlet.6.gz

    En general, los directorios que muestra siempre serán los mismos cuando es un paquete instalado desde el gestor:

    • /usr/bin/ contiene los archivos binarios que se ejecutan cuando lanzas figlet u otro comando desde la terminal.
    • /usr/share contiene archivos extra que permiten funcionar al mismo
    • /usr/share/man contiene los manuales

    Si haces ls al directorio que figlet tiene en /usr/share podrás ver las fuentes que tienes disponibles.

    Desinstalando paquetes

    Bastante simple, sudo dnf remove <paquete>:

    Buscando paquetes

    Vale, ¿pero y si no sabes como se llama un paquete, o quieres comprobar si algo está disponible en tu gestor?

    Puedes buscarlos con sudo dnf search <palabra>, por ejemplo:

    ❯ sudo dnf search discord
[sudo] contraseña para datadiego:
Actualizando y cargando repositorios:
Repositorios cargados.
Campos coincidentes: name (exacta)
 discord.x86_64 All-in-one voice and text chat
Campos coincidentes: summary
 ddate.x86_64   Convert Gregorian dates to Discordian dates
 python3-pypresence.noarch  A Discord Rich Presence Client in Python

    Podemos descargar discord directamente desde el gestor.

    Tambien puedes buscar por términos que aparezcan en la descripción del paquete, por ejemplo sudo dnf search game te dará varios juegos que puedes instalar directamente desde dnf.
