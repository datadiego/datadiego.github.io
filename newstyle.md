# Estilo nuevo para el blog

Tu mision es crear un nuevo estilo visual para este blog.

Ahora mismo usamos un tema ya creado https://risotto.joeroe.io/

Quiero algo al mismo estilo:

- Minimalista
- Inspirado en terminales modernas y ascii art.
- Que use el tema gruvbox que ya estamos usando para todo el contenido, incluyendo los bloques de código
- Usando Jetbrains mono como hacemos actualmente
- Más moderno

Todo debe realizarse en una rama separada a master, llamada newstyle.

No se debe tocar secciones, ni contenido, solo trabajar en el aspecto visual que se muestra. Se debe mantener también la busqueda de posts que ya habia implementada.

Usa de inspiracion las siguientes paginas:

- https://omarchy.org/
- https://plugins.omarchy.org/
- https://webtui.ironclad.sh/
- https://terminalcss.xyz/
